MC: Por que devolver um erro de validação legível ao modelo, em vez de lançar uma exceção que encerra o programa?

- Ela não produz nenhum efeito.
- Ela exige confirmação humana.
- Ela é executada sempre em paralelo.
J: Com idempotência, repetições por laço ou nova tentativa não duplicam o efeito.

DISC[P]: Implemente `calcular(expr)` seguro, sem `eval`: use o módulo `ast`, aceite apenas números, + - * / ** e parênteses e lance `ValueError` para qualquer outra coisa. Teste com `"2*(3+4)"`, `"2**10"`, `"__import__('os')"` e `"1/0"`.
CODE:
import ast, operator

OPS = {ast.Add: operator.add, ast.Sub: operator.sub, ast.Mult: operator.mul, ast.Div: operator.truediv, ast.Pow: operator.pow}

def calcular(expr):
    def ev(n):
        if isinstance(n, ast.Expression):
            return ev(n.body)
        if isinstance(n, ast.Constant) and type(n.value) in (int, float):
            return n.value
        if isinstance(n, ast.BinOp) and type(n.op) in OPS:
            a, b = ev(n.left), ev(n.right)
            if isinstance(n.op, ast.Pow) and abs(b) > 100:
                raise ValueError("expoente grande demais")
            try:
                return OPS[type(n.op)](a, b)
            except ZeroDivisionError:
                raise ValueError("divisão por zero")
        if isinstance(n, ast.UnaryOp) and isinstance(n.op, ast.USub):
            return -ev(n.operand)
        raise ValueError("elemento não permitido: " + type(n).__name__)
    return ev(ast.parse(expr, mode="eval"))

for e in ["2*(3+4)", "2**10", "__import__('os')", "1/0"]:
    try:
        print(e, "->", calcular(e))
    except ValueError as erro:
        print(e, "-> recusado:", erro)
assert calcular("2*(3+4)") == 14 and calcular("2**10") == 1024
ENDCODE

def detectar_laco(chamadas, limite=3):
    seq = 1
    for i in range(1, len(chamadas)):
        seq = seq + 1 if chamadas[i] == chamadas[i - 1] else 1
        if seq >= limite:
            return i
    return None

DISC[P]: Simule 15 tarefas, cada uma com 20 execuções, cuja probabilidade verdadeira de sucesso varia entre tarefas (fáceis e difíceis). Calcule o IC bootstrap de 95% da taxa média (a) reamostrando as 15 tarefas e (b) reamostrando as 300 execuções, e compare as larguras.
CODE:
import numpy as np

rng = np.random.default_rng(0)
p_tarefa = rng.choice([0.2, 0.5, 0.9, 1.0], size=15)
exec_ = (rng.random((15, 20)) < p_tarefa[:, None]).astype(float)
taxas = exec_.mean(axis=1)

def ic(v, n=2000, seed=1):
    r = np.random.default_rng(seed)
    medias = [r.choice(v, len(v), replace=True).mean() for _ in range(n)]
    return np.quantile(medias, [0.025, 0.975])

lo_t, hi_t = ic(taxas)
lo_e, hi_e = ic(exec_.ravel())
print(f"taxa média: {taxas.mean():.3f}")
print(f"(a) por tarefa    : [{lo_t:.3f}; {hi_t:.3f}] largura {hi_t - lo_t:.3f}")
print(f"(b) por execução  : [{lo_e:.3f}; {hi_e:.3f}] largura {hi_e - lo_e:.3f}")
assert (hi_t - lo_t) > (hi_e - lo_e)
ENDCODE
