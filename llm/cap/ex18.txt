DISC[M]: Calcule o intervalo de Wilson de 95% para 14 acertos em 20 casos e dê o veredito para o critério "taxa ≥ 0,70". Repita para 70 acertos em 100.
R: Com 14/20, $\hat p=0{,}70$ e o intervalo vai de cerca de 0,48 a 0,85 (atravessa 0,70): inconclusivo. Com 70/100, o intervalo vai de cerca de 0,60 a 0,78: também atravessa 0,70, inconclusivo. A mesma taxa com mais casos estreita o intervalo, mas quando a taxa observada é igual ao critério, o veredito só muda se a taxa verdadeira estiver longe dele.
CODE:
import math

def wilson(k, n, z=1.96):
    p = k / n; c = 1 + z * z / n
    centro = (p + z * z / (2 * n)) / c
    meia = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / c
    return centro - meia, centro + meia

def veredito(lo, hi, lim):
    return "atende" if lo >= lim else "não atende" if hi < lim else "inconclusivo"

for k, n in [(14, 20), (70, 100)]:
    lo, hi = wilson(k, n)
    print(f"{k}/{n}: [{lo:.3f}; {hi:.3f}] -> {veredito(lo, hi, 0.70)}")
lo, hi = wilson(14, 20)
assert abs(lo - 0.4812) < 0.005 and abs(hi - 0.8541) < 0.005
lo, hi = wilson(70, 100)
assert abs(lo - 0.6038) < 0.005 and abs(hi - 0.7820) < 0.005
assert veredito(*wilson(14, 20), 0.70) == "inconclusivo" and veredito(*wilson(70, 100), 0.70) == "inconclusivo"
ENDCODE

DISC[P]: Implemente uma trilha de auditoria encadeada por hash (`registrar` e `verificar`) e mostre que a alteração de um evento passado é detectada.
R: Cada evento guarda o hash do anterior e o seu próprio, calculado sobre o conteúdo mais o hash anterior; `verificar` recalcula toda a cadeia. Alterar o conteúdo de um evento passado muda o hash esperado e a verificação falha.
CODE:
import hashlib, json

class Trilha:
    def __init__(self):
        self.eventos = []
    def registrar(self, tipo, **dados):
        ant = self.eventos[-1]["hash"] if self.eventos else "0" * 16
        corpo = {"seq": len(self.eventos), "tipo": tipo, "dados": dados}
        h = hashlib.sha256((ant + json.dumps(corpo, sort_keys=True)).encode()).hexdigest()[:16]
        self.eventos.append({**corpo, "hash": h, "ant": ant})
    def verificar(self):
        ant = "0" * 16
        for e in self.eventos:
            corpo = {k: e[k] for k in ("seq", "tipo", "dados")}
            h = hashlib.sha256((ant + json.dumps(corpo, sort_keys=True)).encode()).hexdigest()[:16]
            if e["ant"] != ant or e["hash"] != h:
                return False
            ant = h
        return True

t = Trilha()
for i in range(3):
    t.registrar("consulta", n=i)
assert t.verificar()
t.eventos[1]["dados"]["n"] = 99
assert not t.verificar()
print("ok")
ENDCODE

CRIT: Demonstra a detecção da alteração.
