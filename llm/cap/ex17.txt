MC: Qual das afirmações descreve melhor a diferença entre injeção de prompt direta e indireta?

MC: Qual princípio da LGPD se traduz em mascarar dados pessoais antes de enviá-los a um serviço externo?

DISC[C]: Distinga injeção de prompt direta e indireta e explique por que a indireta é mais difícil de controlar em aplicações com RAG e agentes.
R: Na direta, o usuário escreve a instrução maliciosa. Na indireta, a instrução está em conteúdo que o sistema lê (página, e-mail, documento), e o usuário pode ser inocente. def cpf_valido(texto):
    d = re.sub(r"\D", "", texto)
    if len(d) != 11 or len(set(d)) == 1:
        return False
    for k in (9, 10):
        s = sum(int(d[i]) * (k + 1 - i) for i in range(k))
        r = (s * 10) % 11
        if (0 if r == 10 else r) != int(d[k]):
            return False
    return True

def destino_permitido(destino, dominios, subdominios=False):
    if destino.count("@") != 1:
        return False
    dom = destino.split("@")[1].lower()
    for d in dominios:

    return False

DISC[P]: Implemente `wilson(k, n)` (intervalo de 95%) e compare com o intervalo normal aproximado para 3 sucessos em 40 tentativas. Mostre que o intervalo normal pode sair do intervalo [0, 1] ou subestimar a incerteza.
CODE:
import numpy as np

def wilson(k, n, z=1.96):
    p = k / n; c = 1 + z * z / n
    centro = (p + z * z / (2 * n)) / c
    meia = z * np.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / c
    return centro - meia, centro + meia

def normal(k, n, z=1.96):
    p = k / n; e = z * np.sqrt(p * (1 - p) / n)
    return p - e, p + e

lo_w, hi_w = wilson(3, 40); lo_n, hi_n = normal(3, 40)
print(f"Wilson [{lo_w:.3f}; {hi_w:.3f}] | normal [{lo_n:.3f}; {hi_n:.3f}]")
assert lo_n < 0 <= lo_w and 0.02 < lo_w < 0.03 and 0.19 < hi_w < 0.20
ENDCODE

import numpy as np
from collections import Counter

def k_min(regs):
    return min(Counter(regs).values())
