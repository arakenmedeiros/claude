DISC[C]: Explique, com suas palavras, o que é um modelo de linguagem e por que escrever um texto longo pode ser entendido como a repetição de um passo simples.
R: Um modelo de linguagem estima a probabilidade do próximo token dado o contexto anterior. Para gerar um texto, calcula-se a distribuição sobre o próximo token, escolhe-se um token (por maior probabilidade ou por sorteio), acrescenta-se ao contexto e repete-se o processo. O texto longo resulta da repetição desse passo. A qualidade depende de quão boas são as distribuições estimadas e de como se escolhe o token a cada passo (Capítulo 6).

R: Modelo: parâmetros treinados que mapeiam tokens em probabilidades; falha típica: conhecimento ausente ou resposta inventada. Aplicação: código que monta o prompt, valida e trata erros; falha típica: prompt mal formulado ou saída sem validação. Interface: a forma de interação (chat, voz, API); falha típica: instruções ocultas ou contexto que o usuário não vê. DISC[C]: Por que não se deve usar "ChatGPT" como sinônimo de LLM? Dê dois argumentos.

(2) Os modelos por trás de um produto mudam ao longo do tempo e podem ser vários, além de o produto incluir instruções, filtros e ferramentas. Identificar o produto com o modelo impede atribuir corretamente um erro ou um mérito, e prejudica a reprodutibilidade.

DISC[C]: O que é esparsidade em n-gramas e como os modelos neurais a mitigam?
R: Esparsidade é o fato de que, para vocabulário grande e $n$ crescente, o número de n-gramas possíveis cresce exponencialmente e a maioria nunca aparece no corpus, tornando as contagens pouco informativas. Modelos neurais aprendem representações vetoriais em que tokens semelhantes ficam próximos, o que permite generalizar de contextos vistos para contextos parecidos e reduz a dependência de contagens exatas.

DISC[C]: Descreva, em um parágrafo, a diferença entre plausibilidade e verdade para um texto gerado por um modelo de linguagem.
R: Plausibilidade é a expectativa estatística de um texto segundo os padrões dos dados de treinamento; verdade é a correspondência com os fatos. Um texto pode ser plausível e falso (um erro comum nos dados, uma combinação fluente de fatos inexistentes). A probabilidade atribuída pelo modelo mede a primeira, não a segunda. Por isso é preciso verificar com fontes e medir o desempenho com dados de teste.

DISC[M]: Mostre que, se um modelo atribui probabilidade uniforme $1/V$ a cada passo, a perplexidade é $V$. Aplique para $V=8$.
R: Em $n$ passos, $\ln P = n \ln(1/V) = -n\ln V$. A perplexidade é $e^{-\ln P / n} = e^{\ln V} = V$. Para $V=8$, a perplexidade é 8: o modelo está tão incerto quanto alguém que escolhe ao acaso entre 8 opções. Isso dá a interpretação de "número efetivo de opções".

def logprob_frase(frase, p_cond, ordem=3):
    total = 0.0
    for i, tok in enumerate(frase):
        ctx = tuple(frase[max(0, i - (ordem - 1)):i])
        total += math.log(p_cond[(ctx, tok)])
    return total

DISC[P]: Implemente `treinar_bigramas(frases, k)` que devolva uma função `prob(anterior, token)` com suavização aditiva. Mostre que as probabilidades para um `anterior` somam 1 sobre o vocabulário.
CODE:
from collections import Counter, defaultdict

def treinar_bigramas(frases, k=0.1):
    vocab = sorted({t for f in frases for t in f} | {"<s>"})
    cont = defaultdict(Counter)
    for f in frases:
        seq = ["<s>"] + list(f)
        for a, b in zip(seq, seq[1:]):
            cont[a][b] += 1
    V = len(vocab)
    def prob(anterior, token):
        c = cont[anterior]
        return (c[token] + k) / (sum(c.values()) + k * V)
    return prob, vocab

frases = [["o", "aluno", "lê", "."], ["o", "aluno", "escreve", "."], ["a", "aluna", "lê", "."]]
prob, vocab = treinar_bigramas(frases, k=0.1)
assert abs(sum(prob("aluno", t) for t in vocab) - 1.0) < 1e-12
print(round(prob("aluno", "lê"), 4))
ENDCODE

CRIT: O denominador inclui k vezes o tamanho do vocabulário.
CRIT: Verifica que a soma é 1.
