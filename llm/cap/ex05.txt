import numpy as np

def taxa(s, S, eta_max=1e-3, eta_min=1e-4, w=100):
    if s <= w:
        return eta_max * s / w
    return eta_min + 0.5 * (eta_max - eta_min) * (1 + np.cos(np.pi * (s - w) / (S - w)))

DISC[P]: Implemente `deduplicar(docs, k, limiar)` baseado em Jaccard de shingles de $k$ palavras, mantendo o primeiro de cada grupo de quase duplicatas, e teste com quatro documentos (uma cópia exata, uma quase cópia e um distinto).

def shingles(texto, k=3):
    p = texto.lower().split()
    return {tuple(p[i:i + k]) for i in range(len(p) - k + 1)}

def jaccard(a, b):
    return len(a & b) / len(a | b) if (a | b) else 0.0

def deduplicar(docs, k=3, limiar=0.5):
    S = [shingles(d, k) for d in docs]
    manter = []
    for i, s in enumerate(S):
        if all(jaccard(s, S[j]) < limiar for j in manter):
            manter.append(i)
    return manter

docs = [
    "a biblioteca central funciona de segunda a sexta das sete às vinte e duas horas",
    "a biblioteca central funciona de segunda a sexta das sete às vinte e duas horas",
    "a biblioteca central funciona de segunda a sexta das sete às vinte e três horas",
    "o restaurante universitário serve almoço e jantar todos os dias da semana letiva",
]
assert deduplicar(docs, k=3, limiar=0.5) == [0, 3]

Pipeline: extração, normalização Unicode, identificação de idioma, filtros de qualidade, deduplicação (exata e aproximada), remoção de dados pessoais (por exemplo, CPF, e-mail) e de conteúdo inadequado, divisão em treino/validação/teste por documento, e verificação de sobreposição entre elas. Documentação: ficha de dados com fontes, licenças, filtros, proporções e limitações. Riscos: licenças e direitos autorais, LGPD (dados pessoais), vieses de fontes (linguagem formal), contaminação com benchmarks internos. Prever auditoria e canal de remoção de dados.

DISC[D]: Com orçamento de computação limitado, você deve decidir entre treinar um modelo de 1 bilhão de parâmetros com 20 bilhões de tokens ou um de 3 bilhões com 7 bilhões de tokens, com custo semelhante ($6ND$). Como decidiria?
R: Calcular: $6\times10^9\times2\times10^{10}=1{,}2\times10^{20}$ e $6\times3\times10^9\times7\times10^{9}=1{,}26\times10^{20}$, custos semelhantes. Pela referência de 20 tokens por parâmetro, o primeiro está perto do ponto ótimo de treino, e o segundo estaria subtreinado (cerca de 2,3 tokens por parâmetro). Também considerar custo de inferência (o menor é mais barato) e a tarefa. Decidir por experimentos em escala reduzida e avaliação nas tarefas-alvo, reconhecendo que a regra é uma referência.

DISC[D]: Descreva um plano para evitar contaminação em um benchmark interno de uma empresa que ajustará modelos com dados internos.
R: Separar o conjunto de teste desde o início, com acesso restrito e identificação de versão; criar itens novos e originais; manter o teste fora de repositórios usados para treino; deduplicar treino contra teste (incluindo paráfrases por similaridade de embeddings); registrar a data de criação dos itens; reavaliar com itens novos periodicamente; relatar a análise de contaminação nos resultados; usar intervalos de confiança.
