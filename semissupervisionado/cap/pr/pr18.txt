No **Wine**, com 6 rótulos (2 por classe) e 30 sorteios pareados, compare a regressão logística, o self-training (limiar 0,9) e o Label Spreading (knn, k = 7, alpha = 0,2), tudo com atributos padronizados. Para cada método semissupervisionado, mostre a diferença média para a regressão logística, o intervalo de confiança de 95% por bootstrap e as vitórias e derrotas.

```python
import numpy as np
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.semi_supervised import SelfTrainingClassifier, LabelSpreading

X, y = load_wine(return_X_y=True); X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)
esc = StandardScaler().fit(X_tr); X_tr, X_te = esc.transform(X_tr), esc.transform(X_te); ref, st, ls = [], [], []
for s in range(30):
    r = np.random.RandomState(s); idx = np.concatenate([r.choice(np.where(y_tr == k)[0], 2, replace=False) for k in range(3)]); yp = np.full(len(y_tr), -1); yp[idx] = y_tr[idx]
    ref.append(LogisticRegression(max_iter=3000).fit(X_tr[idx], y_tr[idx]).score(X_te, y_te)); st.append(SelfTrainingClassifier(LogisticRegression(max_iter=3000), threshold=0.9).fit(X_tr, yp).score(X_te, y_te))
    ls.append(LabelSpreading(kernel="knn", n_neighbors=7, alpha=0.2, max_iter=200).fit(X_tr, yp).score(X_te, y_te))
ref, st, ls = map(np.array, (ref, st, ls)); rng = np.random.RandomState(0)
print(f"regressão logística: {100 * ref.mean():.1f}% ± {100 * ref.std():.1f}")
for nome, m in [("self-training", st), ("Label Spreading", ls)]:
    d = m - ref; boot = [rng.choice(d, len(d)).mean() for _ in range(5000)]; lo, hi = np.percentile(boot, [2.5, 97.5])
    print(f"{nome:16s}: {100 * m.mean():.1f}% ± {100 * m.std():.1f} | diferença {100 * d.mean():+.1f} p.p. IC [{100 * lo:+.1f}; {100 * hi:+.1f}] | vitórias/derrotas {int((d > 0).sum())}/{int((d < 0).sum())}")
```
@@NOTE No Wine, com apenas 6 rótulos, a regressão logística obteve **90,3% ± 5,5**; o self-training, 87,1% ± 11,9 (diferença de **−3,2 pontos**, intervalo [−7,0; +0,4], 11 vitórias e 11 derrotas); e o Label Spreading, 86,1% ± 11,4 (**−4,2 pontos**, intervalo [−7,8; −0,6], 12 vitórias e 16 derrotas). Nenhum método semissupervisionado foi melhor: o Label Spreading ficou **abaixo** de modo distinguível de zero, e o self-training, indistinguível. O desvio entre sorteios (de 5,5 a 11,9 pontos) mostra o quanto o resultado depende de **quais 6 exemplos** foram rotulados. Com tão poucos rótulos, os métodos de propagação são instáveis.

No **Digits**, com 50 rótulos (um sorteio, `RandomState(0)`), treine a regressão logística (só rotulados) e o self-training (limiar 0,9) e use as probabilidades no teste. Para cada um, calcule a acurácia geral, a confiança média e a acurácia nas imagens mais confiantes (60% e 40% das imagens).

```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.semi_supervised import SelfTrainingClassifier

X, y = load_digits(return_X_y=True); X = X / 16.0
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)
r = np.random.RandomState(0); idx = np.concatenate([r.choice(np.where(y_tr == d)[0], 5, replace=False) for d in range(10)]); yp = np.full(len(y_tr), -1); yp[idx] = y_tr[idx]
modelos = {"reg. logística": LogisticRegression(max_iter=3000).fit(X_tr[idx], y_tr[idx]), "self-training (0,9)": SelfTrainingClassifier(LogisticRegression(max_iter=3000), threshold=0.9).fit(X_tr, yp)}
print("modelo              | acurácia | confiança média | acurácia nos 60% mais confiantes | nos 40%")
for nome, m in modelos.items():
    P = m.predict_proba(X_te); conf, pred = P.max(1), P.argmax(1); ok = (pred == y_te).astype(float); o = np.argsort(-conf)
    print(f"{nome:19s} | {100 * ok.mean():7.1f}% | {100 * conf.mean():13.1f}% | {100 * ok[o[:int(0.6 * len(ok))]].mean():31.1f}% | {100 * ok[o[:int(0.4 * len(ok))]].mean():.1f}%")
```
@@NOTE A regressão logística e o self-training têm **resultados idênticos**: 86,1% de acurácia e 54,3% de confiança média. O self-training **não adicionou nenhum pseudo-rótulo**, porque, com 50 rótulos, nenhum exemplo sem rótulo atinge a confiança de 0,9 (a confiança média no teste é de apenas 54,3%). Aqui, a regressão logística é **subconfiante** (confiança 54,3% e acurácia 86,1%), o oposto da CNN do Fashion-MNIST. Mesmo assim, a **confiança ordena bem** os casos: nos 60% mais confiantes, a acurácia é de 97,8%, e nos 40% mais confiantes, de 99,5%. A abstenção ajuda, mas o limiar numérico (0,9) não é adequado a este modelo.

```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.semi_supervised import LabelSpreading

X, y = load_digits(return_X_y=True); X = X / 16.0
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)
def sorteio(por, s): r = np.random.RandomState(s); return np.concatenate([r.choice(np.where(y_tr == d)[0], por, replace=False) for d in range(10)])
sup = {}; print("rótulos | reg. logística | Label Spreading")
for por in [2, 5, 10, 20, 40]:
    a, b = [], []
    for s in range(20):
        idx = sorteio(por, s); a.append(LogisticRegression(max_iter=3000).fit(X_tr[idx], y_tr[idx]).score(X_te, y_te))
        if por <= 10: yp = np.full(len(y_tr), -1); yp[idx] = y_tr[idx]; b.append(LabelSpreading(kernel="knn", n_neighbors=10, alpha=0.2, max_iter=200).fit(X_tr, yp).score(X_te, y_te))
    sup[10 * por] = np.mean(a); print(f"{10 * por:7d} | {100 * np.mean(a):13.1f}% | " + (f"{100 * np.mean(b):.1f}%" if b else "--")); 
    if por == 5: ls50 = np.mean(b)
n = np.array(sorted(sup)); acc = np.array([sup[k] for k in n]); eq = np.exp(np.interp(ls50, acc, np.log(n)))
print(f"\nLabel Spreading com 50 rótulos: {100 * ls50:.1f}% | equivale a cerca de {eq:.0f} rótulos supervisionados (interpolação em escala logarítmica)")
```
@@NOTE A regressão logística obtém 73,8% (20 rótulos), 85,8% (50), 90,6% (100), 93,2% (200) e 95,2% (400). O Label Spreading obtém 87,6% (20), **93,4% (50)** e 95,5% (100). O Label Spreading com 50 rótulos (93,4%) equivale a cerca de **213 rótulos supervisionados** (interpolando a curva em escala logarítmica): economiza cerca de **163 rótulos**, ou seja, um fator de uns **4 vezes**. Com 100 rótulos (95,5%), supera a regressão logística com 400. Este é o jeito de **traduzir o ganho em custo**: se rotular um dígito custa R$ 1,00, o método economiza cerca de R$ 160 por 50 rótulos.
@@EX 5 | Reprodutibilidade: sementes e variação | avançado
No **Digits** (50 rótulos), execute o Label Spreading (knn, k = 10, alpha = 0,2) **duas vezes** com a **mesma** semente (`RandomState(0)`) e depois com **dez sementes diferentes**. Mostre se os resultados das duas execuções coincidem e qual o intervalo (mínimo e máximo) e o desvio entre as sementes.

*Pergunta:* por que fixar a semente é importante? O que o intervalo entre sementes diz sobre o relato de um único número?
@@SOL
```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.semi_supervised import LabelSpreading

X, y = load_digits(return_X_y=True); X = X / 16.0
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)
def rodar(semente):
    r = np.random.RandomState(semente); idx = np.concatenate([r.choice(np.where(y_tr == d)[0], 5, replace=False) for d in range(10)]); yp = np.full(len(y_tr), -1); yp[idx] = y_tr[idx]
    return LabelSpreading(kernel="knn", n_neighbors=10, alpha=0.2, max_iter=200).fit(X_tr, yp).score(X_te, y_te)
a, b = rodar(0), rodar(0); print(f"duas execuções com a mesma semente: {100 * a:.2f}% e {100 * b:.2f}% | idênticas: {a == b}")
v = np.array([rodar(s) for s in range(10)])
print(f"dez sementes: mínimo {100 * v.min():.1f}% | máximo {100 * v.max():.1f}% | média {100 * v.mean():.1f}% | desvio {100 * v.std():.1f}")
```
@@NOTE As duas execuções com a **mesma semente** dão **exatamente o mesmo** resultado (93,33%): fixar a semente torna o experimento **reprodutível**. Com **dez sementes diferentes**, o acerto varia de **91,5% a 95,4%** (média 94,0%, desvio 1,2). Portanto, relatar "93,33%" ou "95,4%" a partir de **um único sorteio** seria enganoso: o intervalo entre os extremos é de quase 4 pontos. O relato correto é a média e o desvio de vários sorteios (ou um intervalo de confiança), junto com as sementes usadas.

```python
import numpy as np, torch, torch.nn as nn, torch.nn.functional as F
from scipy import stats
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split, StratifiedKFold
from sklearn.linear_model import LogisticRegression
from sklearn.semi_supervised import SelfTrainingClassifier, LabelSpreading
from sklearn.neighbors import kneighbors_graph

torch.set_num_threads(2)
X, y = load_digits(return_X_y=True); X = X / 16.0
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)
g = kneighbors_graph(X_tr, 10); i, j = g.nonzero(); print(f"Diagnóstico: {100 * np.mean(y_tr[i] == y_tr[j]):.1f}% das arestas (10 vizinhos) ligam exemplos da mesma classe")
cands = [(k, a) for k in [3, 5, 7, 10, 15, 30] for a in [0.2, 0.8]]
def ls_fit(c, rot): yp = np.full(len(y_tr), -1); yp[rot] = y_tr[rot]; return LabelSpreading(kernel="knn", n_neighbors=c[0], alpha=c[1], max_iter=200).fit(X_tr, yp)
Xt, yt, Xtt = torch.tensor(X_tr, dtype=torch.float32), torch.tensor(y_tr), torch.tensor(X_te, dtype=torch.float32)
def mlp_treinar(idx, consistencia, semente, passos=300):
    torch.manual_seed(semente); m = nn.Sequential(nn.Linear(64, 64), nn.ReLU(), nn.Linear(64, 10)); opt = torch.optim.Adam(m.parameters(), lr=0.01); xl, yl = Xt[idx], yt[idx]; xu = Xt[np.setdiff1d(np.arange(len(y_tr)), idx)]
    for p in range(1, passos + 1):
        perda = F.cross_entropy(m(xl + 0.1 * torch.randn_like(xl)), yl)
        if consistencia: perda = perda + 5 * np.exp(-5 * (1 - min(1, p / 100)) ** 2) * F.mse_loss(F.softmax(m(xu + 0.1 * torch.randn_like(xu)), 1), F.softmax(m(xu + 0.1 * torch.randn_like(xu)), 1))
        opt.zero_grad(); perda.backward(); opt.step()
    m.eval(); return m
nomes = ["regressão logística", "MLP só com rotulados", "self-training (0,9)", "Label Spreading (k = 10, alpha = 0,2)", "Label Spreading (CV nos 50)", "MLP + consistência"]
res = {n: [] for n in nomes}; melhor_pred = {}
for s in range(30):
    r = np.random.RandomState(s); idx = np.concatenate([r.choice(np.where(y_tr == d)[0], 5, replace=False) for d in range(10)]); yp = np.full(len(y_tr), -1); yp[idx] = y_tr[idx]
    res[nomes[0]].append(LogisticRegression(max_iter=3000).fit(X_tr[idx], y_tr[idx]).score(X_te, y_te))
    for nome, cons in [(nomes[1], False), (nomes[5], True)]:
        m = mlp_treinar(idx, cons, s)
        with torch.no_grad(): res[nome].append((m(Xtt).argmax(1).numpy() == y_te).mean())
    res[nomes[2]].append(SelfTrainingClassifier(LogisticRegression(max_iter=3000), threshold=0.9).fit(X_tr, yp).score(X_te, y_te))
    res[nomes[3]].append(ls_fit((10, 0.2), idx).score(X_te, y_te))
    cv = [np.mean([np.mean(ls_fit(c, idx[a]).transduction_[idx[b]] == y_tr[idx[b]]) for a, b in StratifiedKFold(5, shuffle=True, random_state=s).split(idx, y_tr[idx])]) for c in cands]
    mc = ls_fit(cands[int(np.argmax(cv))], idx); res[nomes[4]].append(mc.score(X_te, y_te))
    if s == 0: melhor_pred = {"ref": LogisticRegression(max_iter=3000).fit(X_tr[idx], y_tr[idx]).predict(X_te), "ls": ls_fit((10, 0.2), idx).predict(X_te)}
print(f"\nDigits, 50 rótulos, 30 sorteios pareados. Acurácia no teste\nmétodo                                | média ± desvio | dif. p/ reg. logística | IC 95% (bootstrap) | vit./der. | p (Wilcoxon)")
ref = np.array(res[nomes[0]]); rng = np.random.RandomState(0)
for n in nomes:
    v = np.array(res[n]); d = v - ref; extra = ""
    if n != nomes[0]:
        boot = [rng.choice(d, len(d)).mean() for _ in range(5000)]; lo, hi = np.percentile(boot, [2.5, 97.5]); extra = f"{100 * d.mean():+6.1f} p.p.           | [{100 * lo:+5.1f}; {100 * hi:+5.1f}]   | {int((d > 0).sum()):2d}/{int((d < 0).sum()):2d}     | {stats.wilcoxon(d).pvalue:.4f}"
    print(f"{n:37s} | {100 * v.mean():5.1f}% ± {100 * v.std():3.1f} | {extra}")
print("\nAcerto por dígito (sorteio 0): regressão logística x Label Spreading")
for d in range(10): print(f"  dígito {d}: {100 * np.mean(melhor_pred['ref'][y_te == d] == d):5.1f}% x {100 * np.mean(melhor_pred['ls'][y_te == d] == d):5.1f}%")
sup = {}
for por in [5, 10, 20, 40]:
    sup[10 * por] = np.mean([LogisticRegression(max_iter=3000).fit(X_tr[ix], y_tr[ix]).score(X_te, y_te) for ix in [np.concatenate([np.random.RandomState(s).choice(np.where(y_tr == d)[0], por, replace=False) for d in range(10)]) for s in range(20)]])
n = np.array(sorted(sup)); acc = np.array([sup[k] for k in n]); alvo = np.mean(res[nomes[3]])
print(f"\nO Label Spreading (fixo) com 50 rótulos ({100 * alvo:.1f}%) equivale a cerca de {np.exp(np.interp(alvo, acc, np.log(n))):.0f} rótulos supervisionados")

Riscos: o método depende de uma boa representação (aqui, pixels padronizados em 64 dimensões), e as conclusões valem para o Digits, uma base pequena e fácil.
