Acurácia: fração de previsões corretas de um modelo.
Agente: no aprendizado por reforço, quem age em um ambiente e recebe recompensas.
Aprendizado ativo: abordagem em que o modelo escolhe quais exemplos pedir para um humano rotular.
Aprendizado auto-supervisionado: aprendizado em que os rótulos são criados automaticamente a partir dos próprios dados.
Aprendizado de máquina: área da inteligência artificial em que programas melhoram seu desempenho a partir de dados.
Aprendizado indutivo: objetivo de produzir um modelo geral, capaz de prever o rótulo de exemplos novos.
Aprendizado não supervisionado: aprendizado que usa apenas os atributos (X), sem rótulos.
Aprendizado por reforço: aprendizado em que um agente aprende por recompensas e punições.
Aprendizado semissupervisionado: aprendizado que usa poucos exemplos rotulados e muitos exemplos sem rótulo.
Aprendizado supervisionado: aprendizado que usa exemplos com rótulo para todos os dados de treino.
Aprendizado transdutivo: objetivo de rotular os exemplos sem rótulo que já temos, sem modelo para exemplos futuros.
Atributo (feature): característica que descreve um exemplo; uma coluna da tabela de dados.
Baixa densidade (suposição): ideia de que a fronteira de decisão deve passar por região com poucos pontos.
Bayes (teorema de): regra que relaciona P(A | B) com P(B | A), P(A) e P(B).
Classificação: tarefa supervisionada em que o rótulo é uma categoria.
Cluster (grupo): conjunto de exemplos parecidos entre si e diferentes dos demais.
Co-training: método em que dois classificadores, com visões diferentes dos dados, ensinam um ao outro.
Conjunto de teste: dados reservados para medir o desempenho final do modelo.
Conjunto de treino: dados usados para o modelo aprender.
Conjunto de validação: dados usados para escolher parâmetros e comparar modelos.
Consistência (regularização por): exigir que o modelo dê previsões parecidas para versões perturbadas do mesmo exemplo.
Cosseno (similaridade do): medida do ângulo entre dois vetores, entre -1 e 1.
DataFrame: tabela de dados com colunas nomeadas, da biblioteca pandas.
Descasamento de classes (class mismatch): situação em que o conjunto sem rótulo contém classes ausentes do conjunto rotulado.
Desvio padrão: medida de quanto os valores se espalham em torno da média.
Distância euclidiana: distância em linha reta entre dois pontos.
Distância de Manhattan: soma das diferenças absolutas entre os atributos de dois pontos.
Distribuição normal (gaussiana): distribuição em forma de sino, descrita por média e desvio padrão.
Exemplo (instância, amostra): uma linha dos dados.
F1: média harmônica entre precisão e revocação.
Falso negativo (FN): exemplo positivo que o modelo previu como negativo.
Falso positivo (FP): exemplo negativo que o modelo previu como positivo.
fit: método do scikit-learn que ajusta o modelo ou a transformação aos dados de treino.
Fronteira de decisão: linha ou superfície que separa as regiões de cada classe.
Grafo: conjunto de nós ligados por arestas; nos métodos semissupervisionados, cada exemplo é um nó.
Homofilia: fração de vizinhos de um exemplo que têm a mesma classe dele.
Label Spreading: método em grafos que espalha os rótulos pelos vizinhos, com suavização.
Matriz: tabela de números com linhas e colunas.
Matriz de confusão: tabela que cruza as classes reais com as classes previstas.
Média: soma dos valores dividida pelo número de valores.
Modelo: programa que aprendeu com dados e faz previsões.
Modelo de referência (baseline): modelo supervisionado treinado só com os exemplos rotulados, usado para medir o ganho de outros métodos.
NumPy: biblioteca de Python para cálculo com vetores e matrizes.
p.p. (pontos percentuais): diferença absoluta entre duas porcentagens.
pandas: biblioteca de Python para tabelas de dados.
Padronização: transformação que deixa um atributo com média 0 e desvio padrão 1.
Pipeline: objeto que encadeia passos de processamento e um modelo.
Precisão: entre as previsões positivas, a fração que está correta.
predict: método do scikit-learn que devolve as classes previstas.
Pseudo-rótulo: rótulo atribuído pelo próprio modelo, tratado como se fosse verdadeiro.
random_state: semente que torna sorteios reprodutíveis.
Regressão: tarefa supervisionada em que o rótulo é um número.
Revocação (recall): entre os exemplos realmente positivos, a fração que o modelo encontrou.
Rótulo (label): resposta correta de um exemplo.
Self-training (autotreinamento): método em que o modelo rotula os exemplos de que tem mais confiança e aprende com eles.
scikit-learn: biblioteca de Python para aprendizado de máquina.
Sobreajuste (overfitting): quando o modelo decora o treino e generaliza mal.
Subajuste (underfitting): quando o modelo é simples demais para capturar o padrão.
Suavidade (suposição de): ideia de que pontos próximos em região densa têm rótulos iguais.
Suposição de agrupamento: ideia de que pontos do mesmo grupo tendem a ter a mesma classe.
Suposição de variedade (manifold): ideia de que dados de alta dimensão vivem perto de uma superfície de baixa dimensão.
Validação cruzada: técnica que divide os dados em k partes e alterna qual delas é teste.
Variedade (manifold): superfície de baixa dimensão sobre a qual os dados se distribuem aproximadamente.
Vazamento (leakage): quando informação do teste ou da validação escapa para o treino e infla o resultado.
Verdadeiro negativo (VN): exemplo negativo previsto como negativo.
Verdadeiro positivo (VP): exemplo positivo previsto como positivo.
Viés de confirmação: reforço dos próprios erros por um modelo que aprende com seus pseudo-rótulos.
Vizinho mais próximo: o exemplo com menor distância a um ponto de referência.
Calibração: propriedade de um modelo cuja confiança corresponde à frequência real de acerto.
Confiança: maior probabilidade que o modelo atribui entre as classes para um exemplo.
Envoltório (wrapper): método que usa qualquer classificador dentro de um laço, como o self-training.
Limiar de confiança: confiança mínima exigida para aceitar um pseudo-rótulo.
Rodada: uma passagem completa do laço de self-training.
Co-training (co-treinamento): método com dois classificadores treinados em visões diferentes que se ensinam mutuamente.
Independência condicional: duas informações são independentes quando já se conhece a classe; saber uma não ajuda a prever a outra.
Suficiência (de uma visão): propriedade de uma visão que, sozinha, basta para classificar bem.
Tri-training: método de três classificadores em que um exemplo ganha pseudo-rótulo quando dois deles concordam.
Visão (view): um dos conjuntos de atributos, distintos e complementares, que descrevem o mesmo exemplo.
Bootstrap: amostra sorteada com reposição do conjunto de treino.
Algoritmo EM (Expectation-Maximization): procedimento iterativo que alterna estimar probabilidades de classe (passo E) e reestimar parâmetros do modelo (passo M).
BIC (critério de informação bayesiano): medida que equilibra ajuste e complexidade de um modelo; menor é melhor.
Classificador generativo: modelo que descreve como cada classe gera os dados, com p(x | y) e p(y), e classifica pela regra de Bayes.
Classificador discriminativo: modelo que estima diretamente p(y | x) ou a fronteira entre classes.
Cluster-e-rotula: estratégia que agrupa todos os dados e dá a cada grupo a classe mais votada entre os rotulados dele.
Covariância: medida de como dois atributos variam juntos; uma matriz de covariância descreve a forma de uma gaussiana.
Log-verossimilhança: logaritmo da probabilidade que o modelo atribui aos dados; quanto maior, melhor o ajuste.
Mistura de gaussianas (GMM): modelo em que os dados vêm de várias curvas normais combinadas.
Naive Bayes: classificador generativo que supõe os atributos independentes dada a classe.
Responsabilidade: probabilidade de um exemplo pertencer a cada componente, calculada no passo E.
Entropia (de uma previsão): medida de incerteza; é máxima quando as classes são igualmente prováveis e zero quando há certeza.
Margem: distância entre a fronteira de decisão e os exemplos mais próximos de cada classe.
Minimização de entropia: técnica que penaliza previsões incertas nos exemplos sem rótulo, empurrando a fronteira para regiões de baixa densidade.
Perda hinge: perda das SVM, max(0, 1 - y f(x)), que penaliza exemplos dentro da margem ou do lado errado.
S3VM (SVM semissupervisionada): SVM que também exige que a margem evite os exemplos sem rótulo.
SVM (máquina de vetores de suporte): classificador que busca a fronteira de maior margem.
TSVM (SVM transdutiva): S3VM de Joachims, que atribui rótulos provisórios aos exemplos sem rótulo e os revisa por trocas.
Vetores de suporte: exemplos que estão sobre a margem ou a violam e que determinam a fronteira da SVM.
Aresta: ligação entre dois nós de um grafo; nos métodos de grafos, liga exemplos parecidos.
Clamping (fixação): manter os rótulos conhecidos inalterados durante a propagação.
Componente conexo: conjunto de nós de um grafo ligados entre si, sem ligação com os demais.
GNN (rede neural de grafos): rede que combina, em cada nó, os atributos dos vizinhos com pesos aprendidos.
Label Propagation: método em grafos em que cada nó recebe a média dos rótulos dos vizinhos, com os rótulos conhecidos fixos.
Label Spreading: variante da propagação com matriz normalizada e parâmetro alpha, em que os rótulos conhecidos podem mudar.
Matriz de transição: matriz que dá a probabilidade de "passar" de um nó a outro, obtida normalizando os pesos das arestas.
Nó (vértice): ponto de um grafo; nos métodos semissupervisionados, cada exemplo é um nó.
Pureza das arestas: fração das arestas de um grafo que ligam exemplos da mesma classe.
Ponte: aresta que liga exemplos de classes diferentes e propaga rótulos errados.
Aumento de dados (data augmentation): criação de variações de cada exemplo (deslocar, girar, apagar partes, adicionar ruído) que não mudam o rótulo.
Camada convolucional: camada que aplica filtros pequenos deslizando pela imagem para detectar padrões locais.
CNN (rede neural convolucional): rede com camadas convolucionais, apropriada para imagens.
Dropout: técnica de regularização que desliga neurônios ao acaso durante o treino.
Entropia cruzada: perda usada em classificação, que pune probabilidades baixas dadas à classe correta.
Época: uma passagem completa por todos os exemplos de treino.
Função de ativação: função não linear aplicada à saída de um neurônio (ReLU, sigmoide, tangente hiperbólica).
Gradiente: direção de maior aumento da perda; o treino anda na direção oposta.
Lote (batch): grupo de exemplos usado em cada atualização dos pesos.
Max pooling: operação que resume uma região da imagem pelo seu maior valor, reduzindo o tamanho.
MLP (perceptron multicamadas): rede com camadas densas totalmente conectadas.
Neurônio artificial: unidade que soma entradas multiplicadas por pesos, soma um viés e aplica uma ativação.
PyTorch: biblioteca de aprendizado profundo em Python.
ReLU: função de ativação que devolve zero para valores negativos e o próprio valor para positivos.
Retropropagação (backpropagation): algoritmo que calcula os gradientes da perda em relação a todos os pesos da rede.
Taxa de aprendizado: tamanho do passo dado a cada atualização dos pesos.
Consistência (regularização por): exigir que o modelo dê a mesma previsão para versões perturbadas do mesmo exemplo, rotulado ou não.
Π-model: método de consistência em que duas versões perturbadas do mesmo exemplo passam pela mesma rede e suas previsões são aproximadas.
Mean Teacher: método de consistência em que o alvo vem de um "professor", média móvel dos pesos do "aluno".
Média móvel exponencial (EMA): média em que os valores mais recentes pesam mais; no Mean Teacher, é aplicada aos pesos da rede.
Rampa de peso (ramp-up): aumento gradual do peso da perda não supervisionada no início do treino.
UDA (Unsupervised Data Augmentation): consistência entre a previsão em uma versão fraca e em uma versão fortemente aumentada do exemplo.
Afiamento (sharpening): tornar uma distribuição de probabilidades mais concentrada na classe mais provável, por meio de uma temperatura.
Pseudo-rótulo: rótulo que o próprio modelo atribui a um exemplo sem rótulo, em geral a classe mais provável.
Viés de confirmação (confirmation bias): reforço de erros do modelo quando seus pseudo-rótulos errados são usados no treino.
Limiar de confiança: probabilidade mínima da classe mais provável para que uma previsão vire pseudo-rótulo.
Aumento fraco e forte: transformações leves (para gerar o alvo) e intensas (para treinar a rede), como no FixMatch.
Mixup: aumento de dados que mistura duas imagens e seus rótulos com pesos lambda e 1 - lambda.
MixMatch: método que une média e afiamento de previsões, mixup e consistência.
FixMatch: método que usa a previsão na versão fraca, se confiante, como pseudo-rótulo da versão forte.
Bag of words (saco de palavras): representação de um texto pela contagem das palavras, ignorando a ordem.
TF-IDF: ponderação que dá mais peso a palavras frequentes no documento e raras na coleção.
LSA (análise semântica latente): redução de dimensionalidade de matrizes de texto por decomposição em valores singulares.
Stopwords: palavras muito comuns (como "de", "the") que costumam ser removidas.
F1 macro: média do F1 de cada classe, com o mesmo peso para todas, útil quando as classes são desbalanceadas.
Prevalência: proporção de uma classe na população.
Aprendizado auto-supervisionado: aprender representações a partir de dados sem rótulo, inventando uma tarefa cujo "rótulo" vem dos próprios dados.
Tarefa-pretexto (pretext task): tarefa inventada, como prever a rotação aplicada a uma imagem, usada só para aprender uma representação.
Aprendizado contrastivo: aproxima as representações de duas versões do mesmo exemplo (positivos) e afasta as de exemplos diferentes (negativos).
SimCLR: método contrastivo que cria duas versões aumentadas de cada imagem e usa a perda NT-Xent.
NT-Xent: perda contrastiva em que cada exemplo deve reconhecer sua versão par entre todas as demais do lote.
Sonda linear (linear probe): classificador linear treinado sobre um codificador congelado, para medir a qualidade da representação.
Ajuste fino (fine-tuning): continuar o treino de toda a rede, a partir de um codificador pré-treinado, com os exemplos rotulados.
Codificador (encoder): parte da rede que transforma a entrada em uma representação (vetor de atributos).
