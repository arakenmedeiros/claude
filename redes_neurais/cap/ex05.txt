R: O passo depende da **diferença** $S(t)-S(t-1)$ entre épocas consecutivas para os mesmos pesos. Em lote, essa diferença reflete a mudança real do gradiente com o peso. DISC: Escreva uma função em Python que implemente o passo de **um peso** do Quickprop (regras A a D, $\Delta w(t-1)<0$, $=0$ ou $>0$) e teste com os três casos do Exemplo 5.1.

```python
def passo_quickprop(S, S_ant, dw_ant, eps=0.1, mu=1.75):
    sigma = mu / (1.0 + mu)
    if dw_ant == 0:
        return -eps * S                                   # (A) arranque
    sinal = -1.0 if dw_ant < 0 else 1.0                   # sentido do passo anterior
    passo = 0.0
    if sinal * S < 0:                                     # (B) declive ainda pede o mesmo sentido
        passo -= eps * S
    if sinal * S <= sinal * sigma * S_ant:                # declive não diminuiu o bastante
        passo += mu * dw_ant                              # (C) crescimento máximo
    else:
        passo += dw_ant * S / (S_ant - S)                 # (D) passo quadrático
    return passo

for S in (0.30, 0.50, -0.20):
    print(S, round(passo_quickprop(S, 0.60, -0.2), 4))     # -0.23, -0.40, +0.05
```

```python
import numpy as np
from rnbook import MLP

def grad_explicito(W, b, V, c, X, T):
    sig = lambda z: 1 / (1 + np.exp(-z))
    gW, gb, gV, gc = np.zeros_like(W), np.zeros_like(b), np.zeros_like(V), np.zeros_like(c)
    for p in range(len(X)):
        a = np.tanh(W @ X[p] + b); y = sig(V @ a + c)

        dh = (V.T @ do) * (1 - a ** 2)                      # delta oculto
        gW += np.outer(dh, X[p]); gb += dh
    return np.concatenate([gW.ravel(), gb, gV.ravel(), gc])

rng = np.random.default_rng(1); X = rng.normal(size=(7, 3)); T = rng.normal(size=(7, 2))
r = MLP([3, 5, 2], ["tanh", "sigmoide"], semente=2); (W, b), (V, c) = r.desempacotar(r.theta)
print(np.abs(grad_explicito(W, b, V, c, X, T) - r.grad(r.theta, X, T)).max())    # ~1e-16
```
Critérios: usa $\delta^o$ e $\delta^h$ corretos; resultado da ordem de $10^{-16}$.

DISC: Adapte o Quickprop para contar, a cada época, a fração de pesos que usam as regras (A), (C) e (D). Rode no problema anterior (semente 0, 300 épocas) e interprete.
R:
```python
import numpy as np
from rnbook import MLP

def conta_regras(X, T, eps=0.05, mu=1.75, epocas=300, semente=0):
    r = MLP([1, 8, 1], ["tanh", "identidade"], semente=semente); th = r.theta.copy(); N = len(X)
    dw, sa = np.zeros_like(th), np.zeros_like(th); sig = mu / (1 + mu); cont = dict(A=0, C=0, D=0)
    for _ in range(epocas):
        s = r.grad(th, X, T) / N + 1e-4 * th; passo = np.zeros_like(th)
        neg, pos, zer = dw < 0, dw > 0, dw == 0
        passo[neg & (s > 0)] -= eps * s[neg & (s > 0)]; passo[pos & (s < 0)] -= eps * s[pos & (s < 0)]
        passo[zer] -= eps * s[zer]
        cres = (neg & (s >= sig * sa)) | (pos & (s <= sig * sa)); passo[cres] += mu * dw[cres]
        quad = (neg | pos) & ~cres; passo[quad] += dw[quad] * s[quad] / (sa[quad] - s[quad])
        cont["A"] += zer.sum(); cont["C"] += cres.sum(); cont["D"] += quad.sum()
        sa, dw, th = s, passo, th + passo
    tot = sum(cont.values()); return {k: v / tot for k, v in cont.items()}
```
Resultado observado (25 pesos × 300 épocas): regra (A) em $0{,}33\%$ dos casos (só na primeira época), regra (C) em $44{,}7\%$ e regra (D) em $55{,}0\%$. Interpretação: o limite de crescimento $\mu$ é acionado em quase metade das atualizações: a hipótese de parábola raramente é aplicável por inteiro; o passo "quadrático puro" é minoria do tempo.

DISC: Compare o Quickprop e o RPROP (Cap. 6): que informação do gradiente cada um usa, que parâmetros precisam de ajuste e que tipo de falha é típica de cada um.
R: **Quickprop:** usa o **valor** do declive em duas épocas e o último passo; estima a curvatura por peso; parâmetros $\varepsilon$, $\mu$ e decaimento; falha típica: passos quadráticos mal condicionados (curvatura negativa ou parábola ruim) causam picos. **RPROP:** usa apenas o **sinal** do declive, com um passo individual por peso que cresce ou encolhe por fatores fixos; parâmetros $\eta^+,\eta^-,\Delta_0,\Delta_{\min},\Delta_{\max}$; falha típica: mudança de sinal por oscilação ruidosa, que encolhe o passo. Ambos exigem modo de lote e partem do mesmo gradiente do backpropagation.

DISC: Os gráficos do experimento mostram picos ocasionais na perda do Quickprop. Explique a origem e proponha duas salvaguardas, indicando que elas não fazem parte da formulação original.
R: Origem: em alguns pesos, a parábola local estimada pela secante é ruim (curvatura mal estimada ou negativa), e o passo quadrático (ou o de crescimento $\mu$) ultrapassa a região de validade, aumentando temporariamente $E$. Salvaguardas didáticas: (1) limitar o passo absoluto (`passo_max`); (2) detectar aumento da perda e, nesse caso, desfazer o passo e reiniciar o passo anterior de todos os pesos com $-\varepsilon\,S$ (gradiente descendente). Ambas são adaptações (como o `passo_max` do pacote `rnbook`) e podem alterar o desempenho; não são da formulação original de Fahlman.
