DISC: Escreva uma função em Python `gd(grad, x0, eta, tol=1e-8, kmax=10000)` que implemente o gradiente descendente com os critérios de parada da Seção 2.7 e teste-a em $f=\tfrac12(x^2+10y^2)$ com $\eta=0{,}18$ a partir de $(2{,}5;\,1{,}2)$.
R: Solução de referência:
```python
import numpy as np

def gd(grad, x0, eta, tol=1e-8, kmax=10000):
    x = np.array(x0, dtype=float)
    for k in range(kmax):
        g = grad(x)
        if np.linalg.norm(g) < tol:
            return x, k, "gradiente pequeno"
        x = x - eta * g
    return x, kmax, "máximo de iterações"

A = np.diag([1.0, 10.0])
x, k, motivo = gd(lambda v: A @ v, [2.5, 1.2], 0.18)
print(x, k, motivo)
```
Critérios: usa norma do gradiente e limite de iterações; devolve ponto, iterações e motivo; resultado próximo de $(0,0)$.

DISC: Escreva uma função `grad_num(f, x, h=1e-6)` por diferenças centrais e use-a para conferir o gradiente analítico de $f(x,y)=x^2y+y^3$ em $(1,2)$, que é $(4,\,13)$.
R:
```python
import numpy as np

def grad_num(f, x, h=1e-6):
    x = np.asarray(x, dtype=float)
    g = np.zeros_like(x)
    for i in range(x.size):
        e = np.zeros_like(x); e[i] = h
        g[i] = (f(x + e) - f(x - e)) / (2 * h)
    return g

f = lambda v: v[0] ** 2 * v[1] + v[1] ** 3
print(grad_num(f, [1.0, 2.0]))     # aproximadamente [ 4. 13.]
```

```python
x = np.array([0.0, 1.0, 2.0]); y = np.array([1.0, 2.0, 2.0])
```

R:
```python
import numpy as np
x, k = 0.0, 0
while abs(np.exp(x) - 2.0) >= 1e-10 and k < 50:
    x = x - (np.exp(x) - 2.0) / np.exp(x)
    k += 1
    print(k, x)
```
