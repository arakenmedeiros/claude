DISC: Mostre que, para amostras sorteadas independentemente e uniformemente, o gradiente de um minilote é um estimador não enviesado do gradiente médio e calcule a variância em função de $B$.

O estimador do minilote é $\hat{\mathbf{g}}=\frac1B\sum_{i=1}^B\mathbf{g}_{p_i}$, com $\mathbb{E}[\hat{\mathbf{g}}]=\bar{\mathbf{g}}$ (linearidade da esperança). ```python
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)

DISC: Escreva uma função `verificar_gradiente(f, g, theta, h=1e-5)` que compare o gradiente analítico `g(theta)` com o numérico (diferença central) e devolva o erro relativo. Teste com $f(\theta)=\tfrac12\sum\theta_i^2+\sum\sin\theta_i$ e $\nabla f=\theta+\cos\theta$ em $\theta=(0{,}3;\,-1;\,2)$.
R:
```python
import numpy as np

def verificar_gradiente(f, g, theta, h=1e-5):
    theta = np.asarray(theta, float)
    gn = np.zeros_like(theta)
    for i in range(theta.size):
        e = np.zeros_like(theta); e[i] = h
        gn[i] = (f(theta + e) - f(theta - e)) / (2 * h)
    ga = g(theta)
    return np.linalg.norm(ga - gn) / (np.linalg.norm(ga) + np.linalg.norm(gn))

f = lambda t: 0.5 * np.sum(t ** 2) + np.sum(np.sin(t))
g = lambda t: t + np.cos(t)
print(verificar_gradiente(f, g, [0.3, -1.0, 2.0]))   # ~1e-11, bem abaixo de 1e-7
```
Critérios: diferença central; erro relativo definido como no texto; resultado $<10^{-7}$.

DISC: Implemente, só com NumPy, uma rede 2–$H$–1 (tanh na oculta, sigmoide na saída) com backpropagation vetorizado e gradiente descendente em lote para o XOR ($H=3$, $\eta=1$, 6000 épocas, semente fixa). Informe a perda final e as saídas.
R:
```python
import numpy as np
sig = lambda z: 1 / (1 + np.exp(-z))
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], float); T = np.array([[0], [1], [1], [0]], float)
rng = np.random.default_rng(0)
W1 = rng.normal(0, 0.5, (3, 2)); b1 = np.zeros(3); W2 = rng.normal(0, 0.5, (1, 3)); b2 = np.zeros(1)
for _ in range(6000):
    A1 = np.tanh(X @ W1.T + b1); Y = sig(A1 @ W2.T + b2)          # passo direto
    D2 = (Y - T) * Y * (1 - Y)                                    # BP1
    D1 = (D2 @ W2) * (1 - A1 ** 2)                                # BP2
    W2 -= 1.0 * D2.T @ A1; b2 -= 1.0 * D2.sum(0)                  # BP3, BP4
    W1 -= 1.0 * D1.T @ X;  b1 -= 1.0 * D1.sum(0)
print(0.5 * np.sum((Y - T) ** 2), np.round(Y.ravel(), 3))
```
Com a semente 0 (execução do código acima): perda final $1{,}1\times10^{-4}$ e saídas $(0{,}003;\ 0{,}992;\ 0{,}992;\ 0{,}009)$. Critérios: BP1 a BP4 corretos; atualização em lote; saída próxima de $(0,1,1,0)$ (a convergência depende da semente e de $\eta$; reporte o valor obtido).

DISC: Escreva um programa com `MLPRegressor(solver="lbfgs", alpha=0)` e duas saídas que verifique numericamente que `loss_` é igual a $E_{\text{sse}}/(Nm)$, com $E_{\text{sse}}=\tfrac12\sum r^2$. Que valor você obtém?
R:
```python
import numpy as np
from sklearn.neural_network import MLPRegressor

rng = np.random.default_rng(0); X = rng.uniform(-1, 1, (100, 2))
T = np.c_[np.sin(3 * X[:, 0]) + X[:, 1] ** 2, X[:, 0] * X[:, 1]]
m = MLPRegressor(hidden_layer_sizes=(6,), activation="tanh", solver="lbfgs", alpha=0.0,
                 max_iter=3000, tol=1e-10, random_state=0).fit(X, T)
r = m.predict(X) - T
print(m.loss_, 0.5 * np.sum(r ** 2) / (100 * 2))   # ambos ~ 9.4550e-05
```
Resultado observado: os dois valores coincidem ($9{,}455\times10^{-5}$), confirmando que a média é sobre amostras **e** saídas.

DISC: Usando a base Wine, separe 60/20/20 (treino/validação/teste, estratificado), padronize só com o treino e compare `MLPClassifier` com $H=2$, $5$ e $20$ neurônios pela acurácia de validação. Escolha $H$ e avalie no teste uma única vez. Descreva os cuidados.
R:
```python
from sklearn.datasets import load_wine
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neural_network import MLPClassifier

X, y = load_wine(return_X_y=True)
X_a, X_te, y_a, y_te = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)
X_tr, X_va, y_tr, y_va = train_test_split(X_a, y_a, test_size=0.25, random_state=0, stratify=y_a)
constroi = lambda H: make_pipeline(StandardScaler(), MLPClassifier(hidden_layer_sizes=(H,), max_iter=3000, random_state=0))
val = {H: constroi(H).fit(X_tr, y_tr).score(X_va, y_va) for H in (2, 5, 20)}
print(val)                                  # {2: 0.9167, 5: 1.0, 20: 0.9722}
H = max(val, key=val.get)
print(H, constroi(H).fit(X_a, y_a).score(X_te, y_te))
```
Com a semente 0, as acurácias de validação foram $0{,}917$ ($H=2$), $1{,}000$ ($H=5$) e $0{,}972$ ($H=20$); escolhe-se $H=5$. Cuidados: base pequena (36 amostras de validação: uma amostra vale 2,8 pontos); usar várias sementes ou validação cruzada; o teste não deve guiar a escolha; relatar a variabilidade.
