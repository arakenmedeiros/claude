import numpy as np
from scipy.optimize import curve_fit
from rnbook import otimizadores as O

rng = np.random.default_rng(0); x = np.linspace(0, 2, 30)
y = 2.0 * np.exp(0.8 * x) + rng.normal(0, 0.1, 30)

print(r.theta, r.n_iter, r.motivo)

import numpy as np
from rnbook import MLP, otimizadores as O

rng = np.random.default_rng(3); N = 100; X = rng.uniform(0, 1, (N, 1)); T = np.sin(2 * np.pi * X) + rng.normal(0, 0.15, (N, 1))

DISC: Meça o tempo de resolver $(A^TA+I)\mathbf{d}=\mathbf{b}$ para $P=100,200,400,800,1600$ com `np.linalg.solve` e estime o expoente de crescimento. Discuta as implicações para o LMBP.
R:
```python
import time
import numpy as np

tempos = {}
for P in (100, 200, 400, 800, 1600):
    A = np.random.default_rng(0).normal(size=(P, P)); M = A.T @ A + np.eye(P); b = np.ones(P)
    t0 = time.perf_counter()
    for _ in range(3): np.linalg.solve(M, b)
    tempos[P] = (time.perf_counter() - t0) / 3
Ps = list(tempos)
for a, b in zip(Ps[:-1], Ps[1:]):
    print(b, tempos[b], "razão", tempos[b] / tempos[a], "expoente", np.log2(tempos[b] / tempos[a]))
```
Resultado observado (depende da máquina): de $0{,}0002$ s ($P=100$) a $0{,}033$ s ($P=1600$); razões de $\approx4{,}7$ a $4{,}8$ por duplicação, isto é, expoente $\approx2{,}2$ (abaixo de 3, por causa de BLAS e paralelismo, para $P$ pequeno); para $P$ muito maior, o expoente tende a 3. Implicação: o custo do LMBP cresce rapidamente com $P$ (além da memória $P^2$), e o método fica restrito a redes pequenas e médias.

DISC: Usando a decomposição espectral $J^TJ=Q\Lambda Q^T$, mostre que a norma do passo de LM, $\|\mathbf{d}(\mu)\|$, é decrescente em $\mu$ e que $\mathbf{d}(\mu)\approx-\mathbf{g}/\mu$ quando $\mu\to\infty$.
R: $\mathbf{d}(\mu)=-(Q\Lambda Q^T+\mu I)^{-1}\mathbf{g}=-Q(\Lambda+\mu I)^{-1}Q^T\mathbf{g}$. Com $c_i=\mathbf{q}_i^T\mathbf{g}$, $\|\mathbf{d}(\mu)\|^2=\sum_i\dfrac{c_i^2}{(\lambda_i+\mu)^2}$. Cada parcela é decrescente em $\mu>0$ (pois $\lambda_i\ge0$); logo a soma também. Para $\mu\gg\lambda_{\max}$, $(\lambda_i+\mu)^{-1}\approx\mu^{-1}$ e $\mathbf{d}\approx-\mu^{-1}Q Q^T\mathbf{g}=-\mathbf{g}/\mu$. Para $\mu\to0$ com $\lambda_i>0$ para todo $i$, $\mathbf{d}\to$ passo de Gauss–Newton; se algum $\lambda_i=0$ com $c_i\ne0$, o passo cresce sem limite (singularidade): é exatamente o que o amortecimento evita. Isto explica a medição do capítulo: com $\mu=10^{-6}$ a norma foi $201$ e com $\mu=10^{3}$, $0{,}029$.
