DISC: Explique, com suas palavras, a ideia do RPROP e por que ele usa apenas o sinal do gradiente. Cite uma vantagem e uma limitação.
R: O RPROP mantém um passo individual $\Delta_i$ por peso: se o sinal da derivada parcial se mantém entre duas iterações, o passo cresce ($\times\eta^+$); se troca, o mínimo da coordenada foi ultrapassado e o passo encolhe ($\times\eta^-$); o peso se move $-\mathrm{sinal}(g_i)\Delta_i$. DISC: Explique por que, após uma mudança de sinal, faz-se $g_i\leftarrow0$, e o que ocorreria se isso não fosse feito.
R: Na iteração seguinte, o produto $g_i(t-1)g_i(t)$ envolve o gradiente da iteração anterior. Se $g_i(t-1)$ guardasse o valor com o sinal "trocado", o produto poderia novamente ser negativo (por exemplo, no RPROP+, após o retrocesso o peso está de volta ao ponto anterior, onde o sinal é o antigo), e o passo seria reduzido **duas vezes seguidas** sem justificativa. DISC: Mostre que, se a perda for multiplicada por uma constante $c>0$ (por exemplo, trocar a soma pela média), a sequência de atualizações do RPROP (qualquer variante) não muda.
R: O gradiente passa a ser $c\,\mathbf{g}$; como $c>0$, $\mathrm{sinal}(c\,g_i)=\mathrm{sinal}(g_i)$ e os produtos $c^2g_i(t-1)g_i(t)$ têm o mesmo sinal. (Ao contrário do gradiente descendente, cuja taxa depende da escala da perda.)

DISC: Explique a motivação do iRPROP: por que o retrocesso incondicional do RPROP+ pode ser inadequado em uma rede com muitos pesos?

DISC: Escreva uma função com as quatro variantes do RPROP para **um peso** e reproduza as quatro colunas da tabela do Exemplo 6.2 ($E=\tfrac12(w-1)^2$, $w_0=3$, $\Delta_0=0{,}5$, 10 iterações).
R:
```python
import numpy as np

def rprop_1d(var, w0=3.0, delta0=0.5, n=10, eta_mais=1.2, eta_menos=0.5, dmin=1e-6, dmax=50.0):
    E = lambda w: 0.5 * (w - 1.0) ** 2
    g_fun = lambda w: w - 1.0
    w, delta, g_ant, dw_ant, E_ant = w0, delta0, 0.0, 0.0, np.inf
    traj = []
    for _ in range(n):
        traj.append(w)
        g, Et = g_fun(w), E(w); prod = g_ant * g
        if prod > 0: delta = min(delta * eta_mais, dmax)
        elif prod < 0: delta = max(delta * eta_menos, dmin)
        if var == "rprop+":
            dw = -dw_ant if prod < 0 else -np.sign(g) * delta
            g = 0.0 if prod < 0 else g
        elif var == "rprop-":
            dw = -np.sign(g) * delta
        elif var == "irprop-":
            g = 0.0 if prod < 0 else g; dw = -np.sign(g) * delta
        else:  # irprop+
            if prod < 0:
                dw = -dw_ant if Et > E_ant else 0.0; g = 0.0
            else:
                dw = -np.sign(g) * delta
        w, g_ant, dw_ant, E_ant = w + dw, g, dw, Et
    return traj

for v in ("rprop+", "rprop-", "irprop+", "irprop-"):
```

```python
import numpy as np
from rnbook import MLP, otimizadores as O

def exp_pa(seed, ntr=30, nva=30, H=100, noise=0.4, its=3000, pac=100):
    rng = np.random.default_rng(100 + seed); n = ntr + nva + 300
    xs = rng.uniform(0, 1, (n, 1)); ts = np.sin(2 * np.pi * xs) + rng.normal(0, noise, (n, 1))
    xtr, ttr = xs[:ntr], ts[:ntr]; xva, tva = xs[ntr:ntr + nva], ts[ntr:ntr + nva]; xte, tte = xs[ntr + nva:], ts[ntr + nva:]
    r = MLP([1, H, 1], ["tanh", "identidade"], semente=seed, init="he")
    res = O.rprop(r.theta, lambda th: r.perda(th, xtr, ttr) / len(xtr), lambda th: r.grad(th, xtr, ttr) / len(xtr),
                  variante="irprop-", max_iter=its, tol_grad=0,
                  val=lambda th: r.perda(th, xva, tva) / len(xva), paciencia=pac)
    rmse = lambda th: np.sqrt(np.mean((r.prever(xte, th) - tte) ** 2))
    return res.n_iter, rmse(res.theta_melhor), rmse(res.theta)

for s in range(3):
    print(s, exp_pa(s))
```
