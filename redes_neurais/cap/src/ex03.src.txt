DISC: Programe o perceptron com ordem embaralhada e execute-o 5 vezes (sementes 0 a 4) na base Iris, classes setosa e versicolor, com **os quatro atributos**. Relate o número de atualizações e a convergência em cada execução. O resultado muda com a semente?
R:
```python
import numpy as np
from sklearn.datasets import load_iris

def perceptron(X, y, semente, max_epocas=1000):
    rng = np.random.default_rng(semente)
    y = np.where(y > 0, 1, -1)
    w, b, n_upd = np.zeros(X.shape[1]), 0.0, 0
    for epoca in range(max_epocas):
        erros = 0
        for i in rng.permutation(len(y)):
            if y[i] * (X[i] @ w + b) <= 0:
                w, b = w + y[i] * X[i], b + y[i]; erros += 1; n_upd += 1
        if erros == 0:
            return w, b, n_upd, True
    return w, b, n_upd, False

X, y = load_iris(return_X_y=True)
m = y < 2
for s in range(5):
    w, b, n, ok = perceptron(X[m], y[m], s)
    print(s, ok, n)
```

DISC: Escreva uma função que, dado um conjunto aumentado $(\tilde{X},y)$ e um separador unitário $\tilde{\mathbf{w}}^*$, calcule $\gamma$, $R$ e o limite $(R/\gamma)^2$. Aplique ao Exemplo da questão 5 desta lista.
R:
```python
import numpy as np

def limite_perceptron(Xa, y, w_estrela):
    w_estrela = w_estrela / np.linalg.norm(w_estrela)       # garante vetor unitário
    gama = np.min(y * (Xa @ w_estrela))
    R = np.max(np.linalg.norm(Xa, axis=1))
    return gama, R, (R / gama) ** 2

Xa = np.array([[1.0, 1.0], [-1.0, 1.0]]); y = np.array([1, -1])
print(limite_perceptron(Xa, y, np.array([1.0, 0.0])))      # (1.0, 1.414..., 2.0)
```
Critérios: normaliza $\tilde{\mathbf{w}}^*$; verifica $\gamma>0$; resultado $(1;\,\sqrt2;\,2)$.

DISC: Escreva um programa que treine o perceptron nas portas OR e XOR (ordem fixa, 30 épocas) e trace, com Matplotlib, o número de erros por época. O que você observa?
R:
```python
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

def erros_por_epoca(X, t, epocas=30):
    y = np.where(np.array(t) > 0, 1, -1); w, b, hist = np.zeros(2), 0.0, []
    for _ in range(epocas):
        e = 0
        for xi, yi in zip(X, y):
            if yi * (xi @ w + b) <= 0:
                w, b = w + yi * xi, b + yi; e += 1
        hist.append(e)
    return hist

P4 = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], float)
fig, ax = plt.subplots()
ax.plot(erros_por_epoca(P4, [0, 1, 1, 1]), "o-", label="OR")
ax.plot(erros_por_epoca(P4, [0, 1, 1, 0]), "s-", label="XOR")
ax.set_xlabel("época"); ax.set_ylabel("erros"); ax.legend(); fig.savefig("erros.png")
```
Observação: OR chega a 0 erros na 6ª época e permanece; XOR fica em 4 erros em todas as épocas.

DISC: Implemente, em NumPy, a rede 2–2–1 do XOR com os pesos da Eq. [eq:xor-2camadas] e verifique a tabela-verdade. Depois, estenda para uma função `xor_rede(X)` que aceite um lote de pontos com valores reais em $[0,1]^2$ e mapeie $(0{,}9;\,0{,}1)$ e $(0{,}8;\,0{,}9)$.
R:
```python
import numpy as np
degrau = lambda z: (z > 0).astype(int)

def xor_rede(X):
    X = np.atleast_2d(X)
    h1 = degrau(X @ np.array([1.0, 1.0]) - 0.5)       # OR
    h2 = degrau(X @ np.array([-1.0, -1.0]) + 1.5)     # NAND
    return degrau(h1 + h2 - 1.5)                      # AND

P4 = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], float)
print(xor_rede(P4))                                   # [0 1 1 0]
print(xor_rede(np.array([[0.9, 0.1], [0.8, 0.9]])))   # [1 0]
```
Para $(0{,}9;0{,}1)$: $h_1=1$ ($1{,}0-0{,}5>0$), $h_2=1$ ($-1+1{,}5>0$), saída 1. Para $(0{,}8;0{,}9)$: $x_1+x_2=1{,}7$: $h_1=1$, $h_2=0$ ($-1{,}7+1{,}5<0$), saída 0.

DISC: Compare o perceptron e a regressão logística quanto à saída, à função de perda, à garantia de convergência e à interpretação probabilística.
R: **Saída:** perceptron, classe via degrau; logística, $\sigma(z)$, entre 0 e 1. **Perda:** perceptron, critério $-\sum_{\mathcal{M}}y\tilde{\mathbf{w}}^T\tilde{\mathbf{x}}$ (só erros contam); logística, entropia cruzada (todas as amostras contam, com peso maior para erros confiantes). **Convergência:** perceptron converge em número finito de passos se, e só se, os dados forem separáveis; a logística tem perda convexa e, com regularização ou dados não separáveis, converge para o mínimo (sem regularização, em dados separáveis os pesos divergem em norma). **Interpretação:** apenas a logística tem interpretação probabilística (probabilidade posterior sob certas hipóteses).

DISC: Explique o papel do viés $b$ no perceptron. Mostre, com os pontos 1D $x=1$ (classe $+1$) e $x=2$ (classe $-1$), que sem viés não há separador e que com viés há.
R: Sem viés, $z=wx$ e a fronteira passa pela origem. Exigindo $w\cdot1>0$ (classe $+1$) e $w\cdot2<0$ (classe $-1$), teríamos $w>0$ e $w<0$: impossível.
