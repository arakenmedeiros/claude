@@EX 1 | Métricas para classes raras | básico
Gere um problema com 4% de positivos (`make_classification`, 10.000 exemplos, `weights=[0.96]`, `class_sep=0.9`, `random_state=1`). Treine uma floresta aleatória e calcule, no teste: acurácia, precisão, revocação, F1, AUC-ROC e AUC-PR. Compare com o modelo "sempre negativo". Explique por que a AUC-PR é mais informativa que a AUC-ROC neste caso.
@@SOL
```python
from sklearn.datasets import make_classification
from sklearn.dummy import DummyClassifier
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import (accuracy_score, average_precision_score, f1_score,
                             precision_score, recall_score, roc_auc_score)
from sklearn.model_selection import train_test_split

X, y = make_classification(10000, n_features=12, n_informative=5, weights=[0.96], class_sep=0.9, random_state=1)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)
for nome, m in [("sempre negativo", DummyClassifier(strategy="most_frequent")),
                ("floresta", RandomForestClassifier(200, random_state=0))]:
    m.fit(Xtr, ytr)
    prev, p = m.predict(Xte), m.predict_proba(Xte)[:, 1]
    print(f"{nome:16s} acc={accuracy_score(yte, prev):.3f} prec={precision_score(yte, prev, zero_division=0):.3f} "
          f"rev={recall_score(yte, prev):.3f} F1={f1_score(yte, prev):.3f} "
          f"AUC-ROC={roc_auc_score(yte, p):.3f} AUC-PR={average_precision_score(yte, p):.3f}")
print(f"Fração de positivos no teste (piso da AUC-PR): {yte.mean():.3f}")
```
@@NOTE A AUC-ROC da floresta parece alta (acima de 0,8), mas a AUC-PR é bem menor, porque, com poucos positivos, muitos falsos positivos pouco alteram a taxa de falsos positivos (que usa um denominador enorme). A curva PR expõe essa dificuldade.
@@EX 2 | Escolhendo o limiar pelo custo | intermediário
No problema do exercício anterior, suponha que um falso negativo custe R$ 400 e um falso positivo custe R$ 8. Divida os dados em treino, validação e teste (50/25/25). Escolha o limiar que minimiza o custo na **validação** e aplique-o no **teste**. Compare o custo do teste com o limiar 0,5 e com o limiar escolhido.
@@SOL
```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

X, y = make_classification(10000, n_features=12, n_informative=5, weights=[0.96], class_sep=0.9, random_state=1)
Xtr, Xtmp, ytr, ytmp = train_test_split(X, y, test_size=0.5, stratify=y, random_state=0)
Xva, Xte, yva, yte = train_test_split(Xtmp, ytmp, test_size=0.5, stratify=ytmp, random_state=0)
m = RandomForestClassifier(200, random_state=0).fit(Xtr, ytr)
pva, pte = m.predict_proba(Xva)[:, 1], m.predict_proba(Xte)[:, 1]

def custo(p, y, t, c_fn=400, c_fp=8):
    prev = p >= t
    return c_fn * ((~prev) & (y == 1)).sum() + c_fp * (prev & (y == 0)).sum()

limiares = np.linspace(0.01, 0.99, 99)
t_otimo = limiares[int(np.argmin([custo(pva, yva, t) for t in limiares]))]
print(f"Limiar escolhido na validação: {t_otimo:.2f}")
print(f"Custo no teste com limiar 0,50: R$ {custo(pte, yte, 0.5):,.0f}")
print(f"Custo no teste com limiar {t_otimo:.2f}: R$ {custo(pte, yte, t_otimo):,.0f}")
```
@@NOTE O limiar escolhido é bem menor que 0,5, porque o falso negativo é 50 vezes mais caro que o falso positivo. Ele foi escolhido na validação e o custo foi medido no teste, evitando um resultado otimista.
@@EX 3 | Calibração antes e depois | intermediário
Treine uma floresta aleatória e uma floresta calibrada (`CalibratedClassifierCV`, método `isotonic`, `cv=5`) em um problema binário simulado (`make_classification`, 8.000 exemplos, `flip_y=0.05`, `random_state=1`). Calcule o escore de Brier e o erro médio de calibração (diferença absoluta média entre fração observada e probabilidade média por faixa, com 8 faixas por quantil).
@@SOL
```python
import numpy as np
from sklearn.calibration import CalibratedClassifierCV, calibration_curve
from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import brier_score_loss
from sklearn.model_selection import train_test_split

X, y = make_classification(8000, n_features=15, n_informative=6, flip_y=0.05, class_sep=0.7, random_state=1)
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.4, stratify=y, random_state=1)
modelos = {"floresta bruta": RandomForestClassifier(200, random_state=0),
           "floresta calibrada": CalibratedClassifierCV(RandomForestClassifier(200, random_state=0), method="isotonic", cv=5)}
for nome, m in modelos.items():
    p = m.fit(Xtr, ytr).predict_proba(Xte)[:, 1]
    obs, prev = calibration_curve(yte, p, n_bins=8, strategy="quantile")
    print(f"{nome:19s} Brier = {brier_score_loss(yte, p):.4f} | erro médio de calibração = {np.abs(obs - prev).mean():.3f}")
```
@@NOTE A calibração reduz bastante o erro entre probabilidade prevista e frequência observada, e melhora o Brier. Se a probabilidade for usada para calcular preço, risco ou prioridade, calibrar é essencial.
@@EX 4 | O viés da busca de hiperparâmetros | avançado
Em um problema pequeno e ruidoso (`make_classification`, 80 exemplos, 60 atributos, 3 informativos, `flip_y=0.2`, `class_sep=0.4`), repita 5 vezes (sementes 0 a 4) a comparação entre a melhor pontuação da `GridSearchCV` de um SVC e a estimativa por validação cruzada aninhada. Mostre a média das diferenças.
@@SOL
```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import GridSearchCV, StratifiedKFold, cross_val_score
from sklearn.svm import SVC

grade = {"C": [0.01, 0.1, 1, 10, 100], "gamma": [1e-4, 1e-3, 1e-2, 1e-1, 1]}
dif = []
for s in range(5):
    X, y = make_classification(80, n_features=60, n_informative=3, n_redundant=0, class_sep=0.4, flip_y=0.2, random_state=s)
    interno = StratifiedKFold(5, shuffle=True, random_state=s)
    externo = StratifiedKFold(5, shuffle=True, random_state=100 + s)
    otimista = GridSearchCV(SVC(), grade, cv=interno).fit(X, y).best_score_
    honesta = cross_val_score(GridSearchCV(SVC(), grade, cv=interno), X, y, cv=externo).mean()
    dif.append(otimista - honesta)
    print(f"semente {s}: busca = {otimista:.3f} | aninhada = {honesta:.3f} | diferença = {otimista - honesta:+.3f}")
print(f"Viés médio de otimismo: {np.mean(dif):+.3f}")
```
@@NOTE Na média, a melhor pontuação da busca é maior que a estimativa aninhada: parte do bom resultado é sorte de ter escolhido a melhor entre 25 combinações. O viés cresce com poucos dados, muitos atributos e muitas configurações testadas.
@@PROJ Relatório de avaliação rigorosa de um modelo de risco | Cap06
**Contexto.** Um banco quer um modelo de risco de inadimplência. Você receberá dados simulados e deve produzir uma avaliação rigorosa, que seja confiável para a diretoria.

**Dados simulados.** `make_classification` com 12.000 exemplos, 15 atributos (6 informativos), 6% de positivos, `class_sep=0.8`, `random_state=5`. Crie também uma variável de "região" (A: 70%, B: 30%) e faça o atributo 0 ser deslocado em +0,8 para a região B, para criar uma fatia mais difícil.

**Tarefas.**
1. Divida em treino, validação e teste (60/20/20), estratificando por alvo.
2. Compare regressão logística (com padronização) e floresta aleatória por validação cruzada repetida (5 dobras × 3 repetições) em AUC-PR. Reporte média e desvio.
3. Escolha o melhor, calibre-o (isotônica) e reporte o Brier antes e depois, na validação.
4. Escolha o limiar na validação com custos: falso negativo R$ 1.000 e falso positivo R$ 30.
5. No teste, reporte AUC-PR, revocação, precisão e custo total, com intervalo de confiança de 95% (*bootstrap*) para a AUC-PR.
6. Reporte as mesmas métricas por região. Há desigualdade?
7. Escreva uma recomendação de 4 linhas.

**Entregáveis.** Tabela de comparação, escolha do limiar, métricas finais com IC, métricas por região e recomendação.
@@SOL
```python
import numpy as np
import pandas as pd
from sklearn.calibration import CalibratedClassifierCV
from sklearn.datasets import make_classification
from sklearn.ensemble import RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import average_precision_score, brier_score_loss, precision_score, recall_score
from sklearn.model_selection import RepeatedStratifiedKFold, cross_val_score, train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = make_classification(12000, n_features=15, n_informative=6, weights=[0.94], class_sep=0.8, random_state=5)
rng = np.random.default_rng(5)
regiao = rng.choice(["A", "B"], len(y), p=[0.7, 0.3])
X[regiao == "B", 0] += 0.8

idx = np.arange(len(y))
itr, itmp = train_test_split(idx, test_size=0.4, stratify=y, random_state=0)
iva, ite = train_test_split(itmp, test_size=0.5, stratify=y[itmp], random_state=0)
Xtr, ytr, Xva, yva, Xte, yte = X[itr], y[itr], X[iva], y[iva], X[ite], y[ite]

cv = RepeatedStratifiedKFold(n_splits=5, n_repeats=3, random_state=0)
candidatos = {"logreg": make_pipeline(StandardScaler(), LogisticRegression(max_iter=2000)),
              "floresta": RandomForestClassifier(200, min_samples_leaf=3, random_state=0)}
medias = {}
for nome, m in candidatos.items():
    s = cross_val_score(m, Xtr, ytr, cv=cv, scoring="average_precision")
    medias[nome] = s.mean()
    print(f"{nome:9s} AUC-PR (CV) = {s.mean():.3f} ± {s.std():.3f}")
melhor = max(medias, key=medias.get)

bruto = candidatos[melhor].fit(Xtr, ytr)
calibrado = CalibratedClassifierCV(candidatos[melhor], method="isotonic", cv=5).fit(Xtr, ytr)
pva_b, pva_c = bruto.predict_proba(Xva)[:, 1], calibrado.predict_proba(Xva)[:, 1]
print(f"Melhor: {melhor} | Brier na validação: bruto = {brier_score_loss(yva, pva_b):.4f}, calibrado = {brier_score_loss(yva, pva_c):.4f}")

C_FN, C_FP = 1000, 30
custo = lambda p, y, t: C_FN * ((p < t) & (y == 1)).sum() + C_FP * ((p >= t) & (y == 0)).sum()
limiares = np.linspace(0.01, 0.9, 90)
t = limiares[int(np.argmin([custo(pva_c, yva, t_) for t_ in limiares]))]
print(f"Limiar escolhido na validação: {t:.2f}")

pte = calibrado.predict_proba(Xte)[:, 1]
rng = np.random.default_rng(0)
boot = [average_precision_score(yte[i], pte[i]) for i in (rng.integers(0, len(yte), len(yte)) for _ in range(500))]
lo, hi = np.percentile(boot, [2.5, 97.5])
prev = pte >= t
print(f"Teste: AUC-PR = {average_precision_score(yte, pte):.3f} (IC95% {lo:.3f}-{hi:.3f}) | revocação = {recall_score(yte, prev):.3f} | "
      f"precisão = {precision_score(yte, prev):.3f} | custo = R$ {custo(pte, yte, t):,.0f}")

reg_te = regiao[ite]
linhas = []
for r in ["A", "B"]:
    m_ = reg_te == r
    linhas.append({"região": r, "n": int(m_.sum()), "positivos (%)": round(yte[m_].mean() * 100, 1),
                   "AUC-PR": round(average_precision_score(yte[m_], pte[m_]), 3),
                   "revocação": round(recall_score(yte[m_], prev[m_]), 3),
                   "precisão": round(precision_score(yte[m_], prev[m_], zero_division=0), 3)})
print(pd.DataFrame(linhas).to_string(index=False))
```
@@RUBRICA
- Divisão estratificada em treino, validação e teste, com o teste usado uma única vez.
- Comparação por validação cruzada repetida, com média e desvio.
- Calibração verificada com Brier; limiar escolhido na validação com custos explícitos.
- Intervalo de confiança por bootstrap para a métrica final.
- Análise por região com discussão de desigualdade e limites (amostras pequenas na fatia).
- Recomendação objetiva, com ressalvas sobre incerteza, custo e monitoramento.
