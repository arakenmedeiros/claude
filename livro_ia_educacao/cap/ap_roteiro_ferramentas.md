# Apêndice L — Roteiro para avaliar ferramentas de IA

Use este roteiro antes de recomendar ou adotar uma ferramenta em sala de aula ou na instituição. Nenhuma ferramenta é recomendada neste livro. As dimensões iniciais seguem a lógica de classificação de risco do Parecer CNE/CP nº 15/2026 {{CNE, 2026}}. A decisão é sempre local e deve envolver a gestão, a equipe de tecnologia e, quando necessário, o encarregado de proteção de dados.

| Dimensão | Perguntas | Resposta | Alerta? |
|---|---|---|---|
| Classificação de risco | Qual é a finalidade concreta de cada funcionalidade? Em que nível se enquadra (baixo, moderado, alto, excessivo)? Há mais de uma finalidade (prevalece a mais alta)? | | |
| Regra da etapa | O uso previsto é permitido na etapa dos estudantes (educação infantil, anos iniciais, anos finais)? | | |
| Informação do fornecedor | O fornecedor informa o suficiente para classificar o risco? Se não, o uso e a contratação ficam impedidos | | |
| Finalidade pedagógica | Que problema real resolve? Há alternativa mais simples? | | |
| Evidências | Há estudos independentes sobre sua eficácia no seu contexto? | | |
| Idade e público | Qual a idade mínima prevista? É adequada aos estudantes? | | |
| Privacidade | Que dados coleta? Por quanto tempo? Com quem compartilha? Os dados treinam modelos? | | |
| Segurança | Há controle de conteúdo impróprio? Quem acessa os registros? | | |
| Transparência | Explica como funciona e quais são seus limites? | | |
| Acessibilidade | Funciona com leitores de tela, teclado, legendas, contraste? | | |
| Equidade | Funciona bem em português, com diferentes sotaques e contextos? Tem viés conhecido? | | |
| Custos | Há custo para a escola e para as famílias? Dependência de assinatura? | | |
| Infraestrutura | Funciona com a conexão e os dispositivos disponíveis? Há modo offline? | | |
| Controle docente | O professor pode configurar, acompanhar e desativar? | | |
| Aspectos legais | Contrato, termos de uso, LGPD, ECA Digital, direitos autorais, políticas institucionais? | | |
| Dados e treinamento | Dados e conteúdos de estudantes e docentes são usados para treinar modelos de terceiros? (vedado para crianças e adolescentes) | | |
| Governança e contratos | O contrato prevê auditoria, monitoramento, responsabilização do fornecedor e canal de contestação? | | |
| Saída | É possível exportar dados e encerrar o uso sem prejuízo? | | |
