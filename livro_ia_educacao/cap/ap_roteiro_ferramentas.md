# Apêndice L — Roteiro para avaliar ferramentas de IA

Use este roteiro antes de recomendar ou adotar uma ferramenta em sala de aula ou na instituição. Nenhuma ferramenta é recomendada neste livro. A decisão é sempre local e deve envolver a gestão, a equipe de tecnologia e, quando necessário, o encarregado de proteção de dados.

| Dimensão | Perguntas | Resposta | Alerta? |
|---|---|---|---|
| Finalidade pedagógica | Que problema real resolve? Há alternativa mais simples? | | |
| Evidências | Há estudos independentes sobre sua eficácia no seu contexto? | | |
| Idade e público | Qual a idade mínima prevista? É adequada aos estudantes? | | |
| Privacidade | Que dados coleta? Por quanto tempo? Com quem compartilha? Os dados treinam modelos? | | |
| Segurança | Há controle de conteúdo impróprio? Quem acessa os registros? | | |
| Transparência | Explica como funciona e quais são seus limites? | | |
| Acessibilidade | Funciona com leitores de tela, teclado, legendas, contraste? | | |
| Equidade | Funciona bem em português, com diferentes sotaques e contextos? Tem viés conhecido? | | |
| Custos | Há custo para a escola e para as famílias? Dependência de assinatura? | | |
| Infraestrutura | Funciona com a conexão e os dispositivos disponíveis? Há modo offline? | | |
| Controle docente | O professor pode configurar, acompanhar e desativar? | | |
| Aspectos legais | Contrato, termos de uso, LGPD, direitos autorais, políticas institucionais? | | |
| Saída | É possível exportar dados e encerrar o uso sem prejuízo? | | |
