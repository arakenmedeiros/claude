## 2.1 Por que começar pelos dados?

Existe uma frase famosa entre cientistas de dados: **"lixo entra, lixo sai"**. Se os dados forem ruins, o melhor algoritmo do mundo produzirá resultados ruins.

No aprendizado não supervisionado isso é ainda mais grave. Sem gabarito, você pode nem perceber o erro. O algoritmo sempre devolve *alguma* resposta, mesmo quando ela não faz sentido.

Neste capítulo você vai aprender três habilidades essenciais:

1. Entender como os dados são organizados.
2. Medir o quanto dois exemplos se parecem (**distância**).
3. Preparar os dados para que o algoritmo não seja enganado.

## 2.2 Dados como uma tabela de números

Todo algoritmo deste livro enxerga seus dados como uma **matriz**: uma tabela em que cada linha é um exemplo e cada coluna é um atributo.

![f2_matriz](Figura 2.1 — Os dados como matriz: linhas são exemplos; colunas são atributos. Cada linha também é um ponto no espaço.)

Veja um exemplo simples, com clientes de uma padaria:

| Cliente | Idade | Gasto mensal (R$) | Visitas por mês |
|---|---|---|---|
| Ana | 25 | 120 | 8 |
| Bruno | 62 | 340 | 12 |
| Carla | 31 | 95 | 4 |
| Diego | 58 | 310 | 10 |

Cada cliente é um **ponto num espaço de 3 dimensões**. Ana está na posição (25, 120, 8). Bruno em (62, 340, 12). Dois clientes "parecidos" ficam **próximos** nesse espaço.

:::memorize A ideia central
Semelhança = proximidade. Quase todo algoritmo de agrupamento, e muitos de redução de dimensionalidade e de anomalias, depende de uma **medida de distância**.
:::

### 2.2.1 Tipos de atributos

Nem todo atributo é um número comum. Conhecer o tipo orienta toda a preparação.

- **Numérico contínuo:** pode assumir infinitos valores. Ex.: altura, temperatura, preço.
- **Numérico discreto:** valores inteiros contáveis. Ex.: número de filhos.
- **Categórico nominal:** categorias sem ordem. Ex.: cor, cidade, time de futebol.
- **Categórico ordinal:** categorias com ordem. Ex.: "baixo, médio, alto"; nota de 1 a 5 estrelas.
- **Binário:** só dois valores. Ex.: comprou ou não comprou.

:::atencao Cuidado com "números disfarçados"
O CEP e o número da camisa de um jogador são números, mas **não são quantidades**. O CEP 20000 não é "o dobro" do CEP 10000. Trate-os como categorias.
:::

## 2.3 Medindo semelhança: as distâncias

Uma **distância** é uma regra que transforma dois pontos num número que diz "quão longe estão". Quanto maior, mais diferentes.

Para ser uma **métrica** (distância no sentido matemático), a regra deve cumprir quatro propriedades:

1. **Não negatividade:** d(a, b) ≥ 0.
2. **Identidade:** d(a, b) = 0 se, e somente se, a = b.
3. **Simetria:** d(a, b) = d(b, a).
4. **Desigualdade triangular:** d(a, c) ≤ d(a, b) + d(b, c). Ir direto nunca é mais longo que dar uma volta.

### 2.3.1 Distância Euclidiana

É a distância "em linha reta", a que você mediria com uma régua.

$$ d(a, b) = √( (a₁ − b₁)² + (a₂ − b₂)² + … + (a_d − b_d)² ) $$

*Em palavras:* subtraia cada atributo, eleve ao quadrado, some tudo e tire a raiz.

*Exemplo com Ana e Carla:* diferenças (25−31 = −6; 120−95 = 25; 8−4 = 4). Quadrados: 36, 625, 16. Soma: 677. Raiz: ≈ 26,0.

### 2.3.2 Distância de Manhattan

Imagine andar de táxi em Manhattan, onde os quarteirões formam uma grade. Você não corta caminho pelos prédios. Anda em "L".

$$ d(a, b) = |a₁ − b₁| + |a₂ − b₂| + … + |a_d − b_d| $$

Também é chamada de distância L1 ou "do quarteirão". É mais robusta a valores extremos do que a Euclidiana, pois não eleva as diferenças ao quadrado.

### 2.3.3 Distância de Chebyshev

Considera apenas a **maior** diferença entre atributos.

$$ d(a, b) = max( |a₁ − b₁|, …, |a_d − b_d| ) $$

*Analogia:* o rei do xadrez. O número de jogadas que ele precisa para ir de uma casa a outra é a distância de Chebyshev.

### 2.3.4 Distância de Minkowski: a família completa

As três anteriores são casos de uma fórmula única, com um parâmetro *p*:

$$ d_p(a, b) = ( Σ |aᵢ − bᵢ|^p )^(1/p) $$

- p = 1 → Manhattan.
- p = 2 → Euclidiana.
- p → ∞ → Chebyshev.

![f2_distancias](Figura 2.2 — Três formas de medir a distância entre dois pontos na mesma grade.)

![f2_bolas](Figura 2.3 — O "círculo" de raio 1 muda de forma conforme a distância: losango (Manhattan), círculo (Euclidiana) e quadrado (Chebyshev).)

### 2.3.5 Distância (e similaridade) do cosseno

Às vezes a **direção** importa mais que o tamanho. Pense em dois textos que falam do mesmo assunto, um curto e um longo. As palavras aparecem em proporções parecidas, mas as contagens do texto longo são maiores.

A **similaridade do cosseno** mede o ângulo entre os dois vetores:

$$ cos(a, b) = (a · b) / (‖a‖ × ‖b‖) $$

Vale 1 se apontam para a mesma direção, 0 se são perpendiculares e −1 se são opostos. A **distância do cosseno** é 1 − cos(a, b).

![f2_cosseno](Figura 2.4 — Dois vetores com tamanhos muito diferentes, mas mesma direção: distância Euclidiana grande, distância do cosseno zero.)

:::saibamais Quando usar o cosseno?
É a escolha clássica para texto, recomendação e *embeddings* (representações numéricas aprendidas), porque ignora o "volume" e compara o "perfil" (Aggarwal, 2015).
:::

### 2.3.6 Distância de Hamming e de Jaccard

Para dados binários ou conjuntos:

- **Hamming:** conta em quantas posições dois textos de mesmo tamanho diferem. "casa" e "cama" têm Hamming 1.
- **Jaccard:** compara dois conjuntos. É o tamanho da interseção dividido pelo tamanho da união. A distância de Jaccard é 1 menos esse valor.

*Exemplo:* o carrinho de Ana tem {pão, leite, café}. O de Bruno tem {pão, café, açúcar}. Interseção = 2 itens; união = 4 itens. Similaridade = 2/4 = 0,5. Distância = 0,5.

### 2.3.7 Dados mistos: a distância de Gower

E se o cliente tem idade (número), cidade (categoria) e plano (ordinal)? Gower (1971) propôs calcular uma distância parcial por atributo, de 0 a 1, e tirar a média.

- Para números: diferença dividida pela amplitude do atributo.
- Para categorias: 0 se iguais, 1 se diferentes.

É uma das soluções mais usadas quando os tipos de atributos se misturam.

| Distância | Melhor quando… | Cuidado |
|---|---|---|
| Euclidiana | Atributos contínuos, mesma escala | Sensível a valores extremos |
| Manhattan | Há outliers ou muitos atributos | Depende dos eixos |
| Chebyshev | Só a maior diferença importa | Ignora o resto |
| Cosseno | Texto e embeddings | Ignora o tamanho |
| Jaccard | Conjuntos e cestas | Só presença/ausência |
| Gower | Dados mistos | Mais lenta |

## 2.4 Distâncias no Python

```python
import numpy as np
from scipy.spatial import distance

ana   = np.array([25, 120, 8])
carla = np.array([31,  95, 4])

print("Euclidiana:", distance.euclidean(ana, carla))
print("Manhattan :", distance.cityblock(ana, carla))
print("Chebyshev :", distance.chebyshev(ana, carla))
print("Cosseno   :", distance.cosine(ana, carla))

# Matriz com a distância entre TODOS os pares de uma vez
from sklearn.metrics import pairwise_distances
X = np.array([[25, 120, 8],
              [62, 340, 12],
              [31,  95, 4],
              [58, 310, 10]])
D = pairwise_distances(X, metric="euclidean")
print(np.round(D, 1))
```

A matriz `D` é **simétrica** e tem zeros na diagonal. A distância de cada cliente a ele mesmo é zero.

## 2.5 O problema da escala

Observe a tabela da padaria. A coluna **Gasto** vai de 95 a 340. A coluna **Visitas** vai de 4 a 12. Ao calcular a distância Euclidiana, o gasto domina tudo.

Uma diferença de 4 visitas (muito!) pesa quase nada ao lado de uma diferença de R$ 25 no gasto (pouco!). O algoritmo "enxerga" quase só o dinheiro.

![f2_escala](Figura 2.5 — Sem escalar, o atributo de maior amplitude domina os grupos. Depois de padronizar, ambos contribuem igualmente.)

A solução é **colocar todos os atributos em escala comparável**.

### 2.5.1 Padronização (z-score)

Subtrai a média e divide pelo desvio padrão. O resultado tem média 0 e desvio padrão 1.

$$ z = (x − média) / desvio padrão $$

*O que significa?* "Quantos desvios padrão acima ou abaixo da média este valor está?". Um z de 2 é um valor bem alto. Um z de −1 é um pouco abaixo da média.

### 2.5.2 Normalização min-max

Comprime cada atributo para o intervalo [0, 1].

$$ x' = (x − mínimo) / (máximo − mínimo) $$

### 2.5.3 Escalonamento robusto

Usa a **mediana** e o **intervalo interquartil** (a faixa que contém a metade central dos dados). Resiste bem a valores extremos.

$$ x' = (x − mediana) / IQR $$

### 2.5.4 Qual escolher?

- **Padronização:** a escolha padrão para a maioria dos casos (K-means, PCA, GMM).
- **Min-max:** quando você precisa de limites fixos, como em redes neurais com entradas em [0, 1].
- **Robusto:** quando há muitos outliers.

```python
import numpy as np
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler

X = np.array([[25, 120, 8],
              [62, 340, 12],
              [31,  95, 4],
              [58, 310, 10]], dtype=float)

for nome, esc in [("Padronização", StandardScaler()),
                  ("Min-Max", MinMaxScaler()),
                  ("Robusto", RobustScaler())]:
    print(nome)
    print(np.round(esc.fit_transform(X), 2))
```

:::atencao Regra de ouro contra vazamento
Se você for dividir os dados em treino e teste, **ajuste** o escalonador (`fit`) apenas no treino e depois **aplique** (`transform`) no teste. Caso contrário, informação do teste "vaza" para o treino.
:::

## 2.6 Valores ausentes

Dados reais têm buracos. Alguém não informou a renda. Um sensor falhou.

Estratégias comuns:

1. **Remover** linhas ou colunas com muitos buracos. Simples, mas desperdiça dados.
2. **Imputar pela média ou mediana.** Rápido. A mediana é mais segura com outliers.
3. **Imputar pela moda** (valor mais frequente), para categorias.
4. **Imputar pelos vizinhos** (KNN): preenche com a média dos exemplos mais parecidos.
5. **Criar uma coluna indicadora** "estava ausente?". Às vezes a ausência é informativa.

```python
import numpy as np
from sklearn.impute import SimpleImputer, KNNImputer

X = np.array([[25, 120.0],
              [62, np.nan],
              [31,  95.0],
              [np.nan, 310.0]])

print(SimpleImputer(strategy="median").fit_transform(X))
print(KNNImputer(n_neighbors=2).fit_transform(X))
```

## 2.7 Codificando categorias

Os algoritmos só entendem números. Como transformar "azul, verde, vermelho"?

### 2.7.1 Codificação *one-hot*

Cria uma coluna para cada categoria, com 1 ou 0.

| Cor | é_azul | é_verde | é_vermelho |
|---|---|---|---|
| azul | 1 | 0 | 0 |
| verde | 0 | 1 | 0 |
| vermelho | 0 | 0 | 1 |

Assim, nenhuma cor parece "maior" que outra.

### 2.7.2 Codificação ordinal

Para categorias com ordem natural: baixo = 0, médio = 1, alto = 2.

:::atencao Erro clássico
Codificar "azul = 0, verde = 1, vermelho = 2" faz o algoritmo achar que vermelho está "duas vezes mais longe" do azul. Para categorias **sem ordem**, use *one-hot*.
:::

```python
import pandas as pd
from sklearn.preprocessing import OneHotEncoder, OrdinalEncoder

df = pd.DataFrame({"cor": ["azul", "verde", "vermelho", "azul"],
                   "tamanho": ["P", "M", "G", "M"]})

print(pd.get_dummies(df["cor"]))

ord_enc = OrdinalEncoder(categories=[["P", "M", "G"]])
print(ord_enc.fit_transform(df[["tamanho"]]))
```

## 2.8 Selecionando e criando atributos

Nem todo atributo ajuda. Um atributo irrelevante é **ruído**: ele aumenta distâncias sem trazer informação.

- **Remova atributos constantes** ou quase constantes.
- **Remova atributos duplicados** ou altamente correlacionados.
- **Crie atributos novos** a partir de conhecimento do problema (por exemplo, "gasto por visita" = gasto ÷ visitas).
- **Transforme escalas assimétricas.** Valores como renda têm cauda longa. O logaritmo "aproxima" os extremos.

![f2_correlacao](Figura 2.6 — Atributos muito correlacionados carregam informação repetida. Matriz de correlação como mapa de calor.)

## 2.9 A maldição da dimensionalidade

Richard Bellman usou essa expressão em 1957 para descrever as dificuldades de trabalhar com muitos atributos.

### 2.9.1 O espaço fica vazio

Imagine 10 pontos numa reta de 1 metro: eles ficam bem próximos. Agora espalhe os mesmos 10 pontos num quadrado de 1 metro de lado: já ficam mais distantes. Num cubo, mais ainda. Em 100 dimensões, os pontos estão praticamente isolados no meio do nada.

Para "cobrir" o espaço com a mesma densidade, o número de exemplos cresce **exponencialmente** com a dimensão.

### 2.9.2 Todas as distâncias ficam parecidas

Beyer et al. (1999) mostraram que, em alta dimensão, a razão entre a maior e a menor distância tende a 1. Ou seja: **"o vizinho mais próximo" deixa de ser muito mais próximo que "o mais distante"**. Aggarwal, Hinneburg e Keim (2001) mostraram que normas com *p* menor (como Manhattan) sofrem menos com esse efeito.

![f2_maldicao](Figura 2.7 — Experimento: com o aumento do número de dimensões, a diferença relativa entre a menor e a maior distância encolhe.)

### 2.9.3 O que fazer?

- Selecionar apenas atributos relevantes.
- Reduzir dimensionalidade (Capítulos 8 e 9).
- Usar métricas mais robustas (Manhattan, cosseno).
- Coletar mais dados, quando possível.

```python
import numpy as np

rng = np.random.default_rng(0)
for d in [2, 10, 100, 1000]:
    X = rng.random((500, d))
    ref = X[0]
    dist = np.linalg.norm(X[1:] - ref, axis=1)
    contraste = (dist.max() - dist.min()) / dist.min()
    print(f"d={d:5d} -> contraste relativo = {contraste:.2f}")
```

Veja como o contraste cai rapidamente quando *d* aumenta.

## 2.10 Um pipeline limpo no scikit-learn

O scikit-learn permite encadear etapas num **pipeline**. Assim, o mesmo tratamento é aplicado sempre, sem esquecer nenhum passo.

```python
import numpy as np
from sklearn.pipeline import Pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

X = np.array([[25, 120.0, 8],
              [62, 340.0, 12],
              [31, np.nan, 4],
              [58, 310.0, 10],
              [29, 100.0, 5],
              [60, 330.0, 11]])

pipe = Pipeline([
    ("imputar", SimpleImputer(strategy="median")),
    ("escalar", StandardScaler()),
    ("agrupar", KMeans(n_clusters=2, n_init=10, random_state=0)),
])

print(pipe.fit_predict(X))
```

- **Dados** = matriz: linhas são exemplos; colunas, atributos.
- **Semelhança = proximidade**. Escolha a distância certa para os seus dados.
- **Euclidiana** (régua), **Manhattan** (quarteirão), **Chebyshev** (rei do xadrez), **cosseno** (ângulo), **Jaccard** (conjuntos), **Gower** (dados mistos).

:::
