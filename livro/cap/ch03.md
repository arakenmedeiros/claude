## 3.1 A analogia da pizzaria

Você quer abrir **3 pizzarias** numa cidade. Cada morador vai pedir na pizzaria mais próxima. Onde colocá-las?

Uma boa ideia é:

1. Colocar as três em lugares aleatórios.
2. Cada morador escolhe a pizzaria mais próxima.
3. Cada pizzaria **muda de endereço** para o centro dos moradores que atende.
4. Repetir 2 e 3 até ninguém mudar de pizzaria.

Pronto, você acabou de executar o **K-means**. As pizzarias são os **centroides**. Os bairros que cada uma atende são os **grupos**.

:::memorize Em uma frase
K-means divide os dados em *k* grupos, cada um representado pela **média** (centro) de seus pontos.
:::

## 3.2 O algoritmo, passo a passo

O método foi proposto por Lloyd (publicado em 1982) e batizado por MacQueen (1967). A versão mais usada é o **algoritmo de Lloyd**.

**Entrada:** os dados X e o número de grupos *k*.

1. **Inicialização:** escolha *k* pontos como centroides iniciais.
2. **Atribuição:** associe cada ponto ao centroide mais próximo.
3. **Atualização:** recalcule cada centroide como a **média** dos pontos do seu grupo.
4. **Repetição:** volte ao passo 2 até que as atribuições não mudem (convergência) ou se atinja um limite de iterações.

![f3_passos](Figura 3.1 — O K-means em ação: iniciar, atribuir, atualizar e repetir até estabilizar.)

### 3.2.1 Exemplo numérico minúsculo

Temos 6 pontos numa reta: **1, 2, 3, 10, 11, 12**. Queremos *k* = 2.

- **Início:** centroides em 1 e 2.
- **Rodada 1, atribuição:** o ponto 1 vai para o centroide 1. O ponto 2 vai para o centroide 2. O ponto 3 está a 2 do centroide 1 e a 1 do centroide 2, então vai para o 2. Os pontos 10, 11 e 12 também vão para o 2.
- **Rodada 1, atualização:** o grupo A = {1} tem centroide 1. O grupo B = {2, 3, 10, 11, 12} tem centroide 7,6.
- **Rodada 2, atribuição:** o ponto 2 está a 1 do centroide A e a 5,6 do B, então migra para A. O ponto 3 também migra para A (2 contra 4,6). Os pontos 10, 11 e 12 ficam em B.
- **Rodada 2, atualização:** A = {1, 2, 3} tem centroide 2. B = {10, 11, 12} tem centroide 11.
- **Rodada 3:** ninguém muda de grupo. **Convergiu!**

## 3.3 A matemática por trás (sem medo)

O K-means tenta minimizar a **inércia**, também chamada de soma dos quadrados dentro dos grupos (WCSS, do inglês *within-cluster sum of squares*):

$$ J = Σ_k Σ_(x ∈ grupo k) ‖x − μ_k‖² $$

*Em palavras:* para cada ponto, calcule o quadrado da distância até o centro do seu grupo. Some tudo. **Quanto menor, mais compactos os grupos.**

Duas propriedades importantes:

- A cada iteração, J **nunca aumenta**. Por isso o algoritmo sempre termina.
- Mas pode parar num **mínimo local**: uma solução boa, não necessariamente a melhor possível. O problema geral é NP-difícil (ou seja, não se conhece algoritmo rápido que garanta o ótimo) (Jain, 2010).

![f3_voronoi](Figura 3.2 — Cada centroide "domina" uma região do plano chamada célula de Voronoi. As fronteiras entre grupos são retas.)

:::saibamais Por que a média?
Para a distância Euclidiana ao quadrado, a média é exatamente o ponto que minimiza a soma das distâncias dentro de um grupo. É por isso que o passo de atualização usa a média. Se mudar a distância, o centro ideal muda (veja K-medoids, na Seção 3.8).
:::

## 3.4 Colocando a mão na massa

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans

# Dados sintéticos: 3 "nuvens" de pontos
X, _ = make_blobs(n_samples=300, centers=3, cluster_std=1.0, random_state=7)

km = KMeans(n_clusters=3, n_init=10, random_state=0)
rotulos = km.fit_predict(X)

print("Centroides:\n", km.cluster_centers_)
print("Inércia   :", km.inertia_)
print("Iterações :", km.n_iter_)

plt.scatter(X[:, 0], X[:, 1], c=rotulos, s=20)
plt.scatter(*km.cluster_centers_.T, c="red", marker="X", s=200)
plt.title("K-means com k=3")
plt.show()
```

**Atributos úteis do objeto `KMeans`:**

- `cluster_centers_`: as coordenadas dos centroides.
- `labels_`: o grupo de cada ponto.
- `inertia_`: o valor de J.
- `n_iter_`: quantas iterações foram necessárias.

Para classificar **novos** pontos, use `km.predict(novos_pontos)`.

## 3.5 O problema da inicialização

Os centroides iniciais importam muito. Se dois começarem no mesmo grupo natural, o algoritmo pode terminar com uma divisão ruim.

![f3_init](Figura 3.3 — Uma má inicialização leva a uma solução ruim (esquerda). O k-means++ espalha os centros iniciais e costuma acertar (direita).)

Há três remédios.

1. **Rodar várias vezes** (`n_init`) com sementes diferentes e ficar com a menor inércia.
2. **k-means++** (Arthur; Vassilvitskii, 2007): escolhe o primeiro centro ao acaso. Cada centro seguinte é sorteado com probabilidade proporcional ao **quadrado da distância** ao centro mais próximo já escolhido. Isso espalha os centros. O método tem garantia teórica: o resultado é, em média, no máximo O(log *k*) vezes pior que o ótimo.
3. **Fornecer centros iniciais** com conhecimento do problema.

O scikit-learn usa `init="k-means++"` como padrão.

## 3.6 Quantos grupos? O método do cotovelo

O K-means exige que você escolha *k*. Como?

Uma técnica popular é rodar o algoritmo para vários valores de *k* e desenhar a inércia. Ela sempre cai quando *k* cresce (no limite, *k* = *n* dá inércia zero). Procure o ponto em que a queda **desacelera**, o "cotovelo".

![f3_cotovelo](Figura 3.4 — Método do cotovelo: a curva dobra em k = 4, o número verdadeiro de grupos nesses dados.)

```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

X, _ = make_blobs(n_samples=400, centers=4, random_state=3)

ks = range(1, 10)
inercias = [KMeans(n_clusters=k, n_init=10, random_state=0).fit(X).inertia_
            for k in ks]

plt.plot(list(ks), inercias, "o-")
plt.xlabel("k")
plt.ylabel("Inércia")
plt.title("Método do cotovelo")
plt.show()
```

:::atencao O cotovelo nem sempre é nítido
Em dados reais, a curva costuma ser suave e a escolha fica subjetiva. Combine com outros critérios: **silhueta**, **estatística gap** e interpretabilidade (Capítulo 7). Tibshirani, Walther e Hastie (2001) propuseram a estatística *gap* para tornar essa decisão mais objetiva.
:::

## 3.7 Quando o K-means falha

O K-means faz suposições fortes. Quando elas não valem, ele erra, mesmo executando perfeitamente.

1. **Grupos esféricos.** Ele busca "bolas" de tamanho parecido. Formas alongadas, curvas ou aneladas são mal capturadas.
2. **Tamanhos semelhantes.** Grupos muito desiguais em tamanho podem ser "cortados" de modo estranho.
3. **Densidades semelhantes.** Um grupo muito denso ao lado de outro difuso confunde o método.
4. **Sensível a outliers.** A média é puxada por valores extremos.
5. **Exige escalonamento.** Atributos de grande amplitude dominam.
6. **Precisa de *k* de antemão.**
7. **Só numérico.** A "média" de categorias não existe.

![f3_falhas](Figura 3.5 — Três cenários em que o K-means não encontra a estrutura "óbvia" para o olho humano: luas, anéis e elipses alongadas.)

:::dica Como se proteger?
Visualize os dados, escale os atributos, teste mais de um algoritmo e compare. Se os grupos não são "bolas", considere GMM (Capítulo 6), DBSCAN (Capítulo 5) ou agrupamento espectral (Capítulo 6).
:::

## 3.8 Variantes importantes

### 3.8.1 Mini-Batch K-means

Para bases gigantes, usar todos os pontos em cada iteração é lento. O **Mini-Batch** (Sculley, 2010) usa pequenos lotes aleatórios a cada passo. É muito mais rápido, com pequena perda de qualidade.

```python
from sklearn.cluster import MiniBatchKMeans
from sklearn.datasets import make_blobs

X, _ = make_blobs(n_samples=100_000, centers=5, random_state=1)
mb = MiniBatchKMeans(n_clusters=5, batch_size=1024, n_init=3, random_state=0)
mb.fit(X)
print(mb.cluster_centers_.round(2))
```

### 3.8.2 K-medoids (PAM)

Em vez da média, usa um **medoide**: um ponto *real* do conjunto de dados que é o mais central do grupo. Vantagens: robusto a outliers e aceita qualquer distância (Kaufman; Rousseeuw, 1990). Desvantagem: custo maior.

*Analogia:* em vez de pôr a pizzaria no "centro geométrico" (que pode cair num lago), você a coloca no endereço de um morador real.

### 3.8.3 K-modes

Para dados **categóricos**: troca a média pela **moda** (valor mais frequente) e a distância por uma medida de discordância (Huang, 1998).

### 3.8.4 Fuzzy C-means

No agrupamento **difuso** (*fuzzy*), cada ponto pertence a todos os grupos, cada um com um **grau** entre 0 e 1. Um cliente pode ser 70 % "econômico" e 30 % "premium" (Bezdek, 1981).

| Variante | Muda o quê? | Quando usar |
|---|---|---|
| Mini-Batch | Usa lotes | Dados enormes |
| K-medoids | Centro é ponto real | Outliers; qualquer distância |
| K-modes | Moda | Dados categóricos |
| Fuzzy C-means | Pertinência parcial | Fronteiras difusas |

## 3.9 Estudo de caso 1: segmentação de clientes

Uma loja tem, por cliente, três informações: **recência** (dias desde a última compra), **frequência** (compras no ano) e **valor** (gasto total). Essa trinca é conhecida como análise **RFM**.

```python
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

rng = np.random.default_rng(42)
# Três perfis simulados: fiéis, ocasionais e inativos
fieis = np.column_stack([rng.normal(15, 5, 100), rng.normal(30, 5, 100),
                         rng.normal(3000, 500, 100)])
ocasionais = np.column_stack([rng.normal(60, 15, 150), rng.normal(8, 3, 150),
                              rng.normal(700, 200, 150)])
inativos = np.column_stack([rng.normal(250, 40, 80), rng.normal(2, 1, 80),
                            rng.normal(150, 80, 80)])

df = pd.DataFrame(np.vstack([fieis, ocasionais, inativos]),
                  columns=["recencia", "frequencia", "valor"])

Xp = StandardScaler().fit_transform(df)
df["grupo"] = KMeans(n_clusters=3, n_init=10, random_state=0).fit_predict(Xp)

# Perfil médio de cada grupo: é aqui que damos NOMES aos grupos
print(df.groupby("grupo").mean().round(1))
print(df["grupo"].value_counts())
```

Olhando as médias, você nomeia os grupos: "fiéis" (recência baixa, frequência e valor altos), "ocasionais" e "inativos". Cada um recebe uma estratégia: programa de fidelidade, cupons e campanha de reativação.

## 3.10 Estudo de caso 2: compressão de imagem por cores

Uma foto colorida tem milhares de cores. Podemos usar K-means para escolher só **8** cores representativas (a **paleta**) e repintar cada pixel com a cor mais próxima. É a chamada **quantização de cores**.

![f3_compressao](Figura 3.6 — Quantização de cores com K-means: da imagem original a versões com 32, 8 e 3 cores.)

```python
import numpy as np
from sklearn.cluster import KMeans

# Imagem sintética 64x64 RGB (gradiente colorido)
h, w = 64, 64
img = np.zeros((h, w, 3))
img[..., 0] = np.linspace(0, 1, w)[None, :]
img[..., 1] = np.linspace(0, 1, h)[:, None]
img[..., 2] = 0.5

pixels = img.reshape(-1, 3)             # cada pixel vira um ponto 3D (R,G,B)
km = KMeans(n_clusters=8, n_init=3, random_state=0).fit(pixels)
img_q = km.cluster_centers_[km.labels_].reshape(h, w, 3)

print("Cores únicas antes:", len(np.unique(pixels.round(3), axis=0)))
print("Cores únicas depois:", len(np.unique(img_q.round(3), axis=0)))
```

Cada pixel passa a ser descrito por um **índice** (de 0 a 7) em vez de três números. Isso reduz muito o tamanho do arquivo. É a mesma ideia da **quantização vetorial** usada em compressão (Lloyd, 1982).

## 3.11 Boas práticas

- **Escale** os atributos antes.
- **Rode várias inicializações** (`n_init` ≥ 10).
- **Teste vários *k*** e use mais de um critério.
- **Inspecione** os grupos: tamanhos, perfis médios, exemplos reais.
- **Verifique a estabilidade:** mude a semente ou reamostre. Os grupos se mantêm?
- **Documente** como nomeou os grupos.

## Resumo do capítulo

:::memorize Cartões de memorização
- **K-means:** atribuir ao centro mais próximo → recalcular a média → repetir.
- **Minimiza** a inércia (soma dos quadrados dentro dos grupos).
- **Sempre converge**, mas talvez a um mínimo local.
- **k-means++** melhora a inicialização.
- **Cotovelo** ajuda a escolher *k*, mas não é infalível.
- **Falha** com grupos não esféricos, desiguais ou com outliers.
- **Variantes:** Mini-Batch, K-medoids, K-modes, Fuzzy C-means.
:::
