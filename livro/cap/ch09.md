## 9.1 Quando a linha reta não basta

O PCA projeta os dados em **planos**. Mas e se os dados estiverem "enrolados"?

Pense num **tapete enrolado** (como um rocambole). Dois pontos em voltas vizinhas estão muito próximos em linha reta, mas, para ir de um ao outro **andando sobre o tapete**, é preciso percorrer um longo caminho.

![f9_rocambole](Figura 9.1 — O "rocambole suíço" (Swiss roll): em 3D, pontos de voltas diferentes parecem próximos. Desenrolado, vemos a estrutura real em 2D.)

## 9.2 A hipótese da variedade

Uma **variedade** (*manifold*) é uma superfície que, vista de perto, parece plana, mesmo que globalmente seja curva. A superfície da Terra é o exemplo clássico: localmente parece um plano, mas é uma esfera.

A **hipótese da variedade** diz que dados de alta dimensão geralmente ficam sobre (ou perto de) uma variedade de **dimensão muito menor** (Bengio; Courville; Vincent, 2013; Roweis; Saul, 2000).

*Exemplo:* fotos de um rosto girando. Cada foto tem milhares de pixels, mas o que varia é basicamente **um parâmetro**: o ângulo de rotação. Os dados vivem numa curva de 1 dimensão dentro de um espaço de milhares.

O objetivo do aprendizado de variedades é **desenrolar** a estrutura e revelar essa dimensão intrínseca.

## 9.3 MDS: Escalonamento Multidimensional

### 9.3.1 A ideia do mapa de cidades

Suponha que você só tenha uma **tabela de distâncias** entre cidades, como nas antigas tabelas de quilometragem de estrada. Dá para reconstruir um **mapa**? Sim! Esse é o problema do **MDS** (*Multidimensional Scaling*).

![f9_mds_cidades](Figura 9.2 — MDS reconstrói o mapa de capitais brasileiras a partir apenas das distâncias entre elas. (O mapa pode sair girado ou espelhado.))

O MDS busca posições em 2D (ou 3D) tais que as distâncias no mapa sejam **o mais parecidas possível** com as distâncias originais. Mede-se o erro com o **stress**:

$$ stress = √( Σ (d_original − d_mapa)² / Σ d_original² ) $$

Quanto menor, melhor (Kruskal, 1964; Cox; Cox, 2001).

### 9.3.2 Dois sabores

- **MDS clássico (de Torgerson):** usa autovetores. Se as distâncias são Euclidianas, equivale ao PCA.
- **MDS métrico por stress (SMACOF):** otimiza iterativamente o stress.
- **MDS não métrico:** preserva apenas a **ordem** das distâncias, útil quando só há ranking de semelhança.

```python
import numpy as np
from sklearn.manifold import MDS
from sklearn.metrics import pairwise_distances

rng = np.random.default_rng(0)
pontos = rng.normal(size=(30, 2))                     # mapa "secreto"
D = pairwise_distances(pontos)                         # só conhecemos as distâncias

mds = MDS(n_components=2, dissimilarity="precomputed", random_state=0, n_init=4)
rec = mds.fit_transform(D)
print("Stress final:", round(mds.stress_, 4))
```

## 9.4 Isomap: distâncias geodésicas

O **Isomap** (Tenenbaum; de Silva; Langford, 2000) melhora o MDS usando a distância certa para variedades.

A **distância geodésica** é a distância medida **ao longo da superfície**. É a diferença entre a distância de voo (linha reta) e a distância por rodovia.

**Passos do Isomap:**

1. Conecte cada ponto aos seus *k* vizinhos mais próximos (grafo).
2. Calcule a distância do **menor caminho** no grafo entre todos os pares (aproxima a geodésica).
3. Aplique o MDS a essas distâncias.

![f9_geodesica](Figura 9.3 — Distância euclidiana (tracejada) versus geodésica (curva) entre dois pontos da variedade, aproximada por caminhos no grafo de vizinhos.)

```python
import numpy as np
from sklearn.datasets import make_swiss_roll
from sklearn.manifold import Isomap
from sklearn.decomposition import PCA

X, t = make_swiss_roll(n_samples=1500, noise=0.05, random_state=0)

iso = Isomap(n_neighbors=12, n_components=2).fit_transform(X)
pca = PCA(n_components=2).fit_transform(X)

# t = posição real ao longo do rocambole. Quanto maior a correlação, melhor desenrolou.
print("Corr(t, 1ª coord. Isomap):", abs(np.corrcoef(t, iso[:, 0])[0, 1]).round(2))
print("Corr(t, 1ª coord. PCA)   :", abs(np.corrcoef(t, pca[:, 0])[0, 1]).round(2))
```

**Limitações:** sensível a ruído (atalhos no grafo), exige que o grafo seja conectado, caro (*n*²).

## 9.5 LLE: Embedding Linear Local

O **LLE** (*Locally Linear Embedding*; Roweis; Saul, 2000) parte da ideia: "cada ponto pode ser reconstruído como **combinação** dos vizinhos".

1. Para cada ponto, ache pesos que o reconstruam a partir dos seus *k* vizinhos.
2. Procure coordenadas de baixa dimensão que mantenham **esses mesmos pesos**.

*Analogia:* descrever a posição de cada casa por "um pouco à direita da padaria e bem perto da escola". Essas relações locais se mantêm quando o mapa é desenrolado.

## 9.6 t-SNE

### 9.6.1 O problema que ele resolve

Queremos um mapa 2D em que **vizinhos continuem vizinhos**. O t-SNE (*t-distributed Stochastic Neighbor Embedding*; van der Maaten; Hinton, 2008) é hoje uma das ferramentas de visualização mais usadas, especialmente em biologia e aprendizado profundo.

### 9.6.2 A ideia, em linguagem simples

1. **No espaço original**, para cada ponto, calcule a **probabilidade** de cada outro ponto ser seu "vizinho". Pontos próximos têm alta probabilidade; distantes, quase zero. Usa-se uma gaussiana em volta de cada ponto.
2. **No mapa 2D**, comece com posições aleatórias e calcule probabilidades parecidas, mas usando uma distribuição **t de Student** (de caudas pesadas).
3. **Aproxime** os dois conjuntos de probabilidades, minimizando a **divergência de Kullback-Leibler** (uma medida de diferença entre distribuições), por descida do gradiente.
4. Os pontos se movem no mapa: quem era vizinho se **atrai**; quem não era se **repele**.

*Analogia:* uma festa. No início, as pessoas estão espalhadas aleatoriamente. Quem tem afinidade se aproxima. Quem não tem se afasta. No fim, formam-se rodinhas.

![f9_tsne_idea](Figura 9.4 — O t-SNE alterna forças de atração (vizinhos) e repulsão (não vizinhos) até formar um mapa estável.)

### 9.6.3 Por que a distribuição t?

Em baixa dimensão há **menos espaço**. Muitos pontos moderadamente distantes no espaço original não cabem todos "a uma distância moderada" no mapa e acabariam amontoados no centro (problema da *crowding*). As **caudas pesadas** da t de Student permitem que pontos não vizinhos fiquem bem afastados, abrindo espaço entre as rodinhas.

### 9.6.4 A perplexidade

O principal parâmetro é a **perplexidade**. Interprete-a como o "número aproximado de vizinhos que cada ponto considera". Valores típicos: **5 a 50**.

- **Baixa:** foca em estrutura muito local. Pode fragmentar grupos em pedaços.
- **Alta:** enxerga estruturas mais globais. Pode fundir grupos.

![f9_tsne_perplexidade](Figura 9.5 — O mesmo conjunto de dígitos projetado com perplexidades 5, 30 e 100. O resultado muda; teste vários valores.)

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.manifold import TSNE

X, y = load_digits(return_X_y=True)
Z = TSNE(n_components=2, perplexity=30, init="pca",
         learning_rate="auto", random_state=0).fit_transform(X)

plt.scatter(Z[:, 0], Z[:, 1], c=y, cmap="tab10", s=8)
plt.colorbar(label="Dígito")
plt.title("t-SNE dos dígitos manuscritos")
plt.show()
```

### 9.6.5 Como ler um t-SNE (e como não ler)

Kobak e Berens (2019) e outros autores alertam para armadilhas:

1. **O tamanho dos grupos não significa nada.** O t-SNE adapta a escala local; grupos densos e esparsos aparecem com tamanhos parecidos.
2. **A distância entre grupos distantes quase não significa nada.** Só a vizinhança local é confiável.
3. **A forma pode enganar.** Ruído pode parecer estrutura.
4. **O resultado varia** com a semente aleatória e a perplexidade. Rode mais de uma vez.
5. **Não há mapeamento para novos pontos** na versão original: ele não "aprende uma função".

:::atencao Regra de segurança
Use o t-SNE para **explorar e comunicar**, não como prova. Confirme as descobertas com outras técnicas (como silhueta ou testes estatísticos).
:::

### 9.6.6 Dicas práticas

- **Reduza antes** a 30–50 dimensões com PCA. Acelera e remove ruído.
- Use `init="pca"` para uma inicialização mais estável.
- Rode por tempo suficiente (`max_iter` ≥ 1000).
- Para bases grandes, use a implementação Barnes-Hut (padrão) ou FIt-SNE (Linderman et al., 2019).

## 9.7 UMAP

### 9.7.1 O que é

O **UMAP** (*Uniform Manifold Approximation and Projection*; McInnes; Healy; Melville, 2018) é uma técnica mais recente, que se tornou muito popular, sobretudo em análise de células individuais (Becht et al., 2019).

### 9.7.2 A ideia (sem a matemática pesada)

Possui base teórica em geometria e topologia, mas o procedimento prático tem dois passos:

1. **Construir um grafo "difuso" de vizinhos** em alta dimensão. Cada ligação tem um peso entre 0 e 1 (a "força" da vizinhança), calibrado localmente.
2. **Encontrar um layout** em baixa dimensão cujo grafo seja o mais parecido possível, usando atração e repulsão, como no t-SNE, mas com uma função de custo diferente (entropia cruzada).

### 9.7.3 Parâmetros principais

- **n_neighbors:** tamanho da vizinhança local (como a perplexidade). Pequeno → detalhes locais; grande → estrutura global. Padrão: 15.
- **min_dist:** o quão compactos os pontos podem ficar no mapa. Pequeno → blocos densos; grande → pontos mais espalhados. Padrão: 0,1.
- **metric:** a distância usada (euclidiana, cosseno etc.).

```python
import numpy as np
import umap
from sklearn.datasets import load_digits

X, y = load_digits(return_X_y=True)
Z = umap.UMAP(n_neighbors=15, min_dist=0.1, random_state=0).fit_transform(X)
print(Z.shape)

# Diferença importante: o UMAP aprende uma função, então transforma pontos novos.
modelo = umap.UMAP(n_neighbors=15, random_state=0).fit(X[:1500])
Z_novos = modelo.transform(X[1500:])
print("Pontos novos projetados:", Z_novos.shape)
```

O UMAP é instalado à parte: `pip install umap-learn`.
:::

### 9.7.4 UMAP versus t-SNE

| Aspecto | t-SNE | UMAP |
|---|---|---|
| Velocidade | Mais lento | Mais rápido em bases grandes |
| Estrutura global | Fraca | Em geral melhor preservada |
| Pontos novos | Não (original) | Sim (`transform`) |
| Parâmetro principal | Perplexidade | n_neighbors, min_dist |
| Base teórica | Probabilidades e KL | Topologia e grafos difusos |
| Cuidados | Tamanho e distância entre grupos não significam nada | Idem; não confie cegamente na distância global |

:::atencao Não há mágica
Estudos recentes mostram que boa parte da "melhor estrutura global" do UMAP vem da **inicialização** (por exemplo, PCA ou espectral). Com boa inicialização, o t-SNE se aproxima do UMAP na preservação global (Kobak; Linderman, 2021).
:::

## 9.8 Outras técnicas relevantes

- **LLE modificado e Hessian LLE:** variações mais estáveis do LLE.
- **Laplacian Eigenmaps** (Belkin; Niyogi, 2003): usa autovetores do grafo Laplaciano (veja o Capítulo 6!).
- **Diffusion maps** (Coifman; Lafon, 2006): usa "difusão" no grafo para capturar estrutura em várias escalas.
- **PHATE** (Moon et al., 2019): foca na preservação de trajetórias contínuas em dados biológicos.
- **Autoencoders** (Capítulo 12): a versão neural da redução não linear.

## 9.9 Como avaliar uma projeção?

Como saber se o mapa 2D é fiel? Algumas medidas:

- **Confiança (*trustworthiness*) e continuidade** (Venna; Kaski, 2006): medem se os vizinhos no mapa eram vizinhos no original e vice-versa.
- **Preservação dos k vizinhos:** proporção de vizinhos que se mantêm.
- **Correlação das distâncias:** entre original e mapa (mais útil para estrutura global).

```python
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE, trustworthiness

X, y = load_digits(return_X_y=True)
for nome, Z in [("PCA ", PCA(2).fit_transform(X)),
                ("t-SNE", TSNE(2, perplexity=30, init="pca", random_state=0).fit_transform(X))]:
    print(nome, "trustworthiness (k=10):", round(trustworthiness(X, Z, n_neighbors=10), 3))
```

## 9.10 Um guia de escolha

1. **Pensando em visualizar?** Comece por PCA (rápido, global). Depois t-SNE ou UMAP.
2. **Precisa transformar novos dados?** PCA, Kernel PCA ou UMAP.
3. **Base enorme?** UMAP ou PCA aleatorizado.
4. **Quer preservar a geometria global?** Isomap ou MDS.
5. **Precisa de componentes interpretáveis?** PCA, NMF.

:::memorize Cartões de memorização
- **Variedade:** os dados vivem numa superfície de dimensão menor, enrolada em alta dimensão.
- **Geodésica** = distância sobre a superfície.
- **MDS** reconstrói o mapa a partir de distâncias.
- **Isomap** = grafo + caminhos mínimos + MDS.
- **t-SNE** preserva vizinhanças locais; perplexidade ≈ nº de vizinhos.
- **No t-SNE**, tamanho e distância entre grupos não são confiáveis.
- **UMAP** é rápido, aprende função e costuma preservar mais estrutura global.
