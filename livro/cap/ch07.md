## 7.1 O dilema do juiz sem regras

No futebol, o juiz tem um livro de regras. No aprendizado supervisionado, também: o gabarito diz quem acertou.

No agrupamento, **não há livro de regras**. Se um algoritmo diz que há 4 grupos e outro diz que são 6, quem está certo? Talvez os dois, talvez nenhum.

:::atencao O algoritmo sempre responde
Mesmo com dados puramente aleatórios, o K-means entrega *k* grupos. Isso não prova que existam grupos reais. Avaliar é separar descoberta de miragem.
:::

Existem três famílias de avaliação (Jain; Dubes, 1988; Halkidi; Batistakis; Vazirgiannis, 2001):

![f7_familias](Figura 7.1 — As três famílias de avaliação: interna, externa e relativa.)

1. **Validação interna:** usa apenas os dados e os grupos. Mede coesão e separação.
2. **Validação externa:** compara os grupos com rótulos de referência conhecidos (se houver).
3. **Validação relativa:** compara várias soluções (por exemplo, vários *k*) e escolhe a melhor.

## 7.2 Antes de tudo: existe estrutura nos dados?

Antes de avaliar grupos, pergunte: **há grupos para encontrar?**

A **estatística de Hopkins** testa a *tendência de agrupamento* (Hopkins; Skellam, 1954; Banerjee; Dave, 2004). A ideia:

1. Sorteie alguns pontos **reais** dos dados e meça a distância de cada um a seu vizinho mais próximo (w).
2. Sorteie o mesmo número de pontos **artificiais**, uniformemente espalhados na região, e meça a distância ao vizinho real mais próximo (u).
3. Calcule H = Σu^d / (Σu^d + Σw^d), em que *d* é o número de atributos (cada distância é elevada a *d*, como na definição original).

**Interpretação:**

- H ≈ 0,5: dados parecem uniformes (sem grupos).
- H próximo de 1: dados fortemente agrupáveis.
- H próximo de 0: dados muito regulares (como uma grade).

![f7_tendencia](Figura 7.2 — Dados uniformes (esquerda) versus dados agrupados (direita). A estatística de Hopkins diferencia os dois.)

```python
import numpy as np
from sklearn.neighbors import NearestNeighbors
from sklearn.datasets import make_blobs

def hopkins(X, m=None, seed=42):
    rng = np.random.default_rng(seed)
    n, d = X.shape
    m = m or max(10, int(0.1 * n))
    nn = NearestNeighbors(n_neighbors=2).fit(X)
    idx = rng.choice(n, m, replace=False)
    w = nn.kneighbors(X[idx], 2)[0][:, 1]          # vizinho mais próximo (exclui ele mesmo)
    U = rng.uniform(X.min(0), X.max(0), (m, d))
    u = nn.kneighbors(U, 1)[0][:, 0]
    return (u ** d).sum() / ((u ** d).sum() + (w ** d).sum())

rng = np.random.default_rng(0)
uniforme = rng.random((500, 2))
agrupado, _ = make_blobs(500, centers=4, random_state=2)

print("Hopkins uniforme:", round(hopkins(uniforme), 2))
print("Hopkins agrupado:", round(hopkins(agrupado), 2))
```

## 7.3 Validação interna

### 7.3.1 Coesão e separação

Um bom agrupamento tem:

- **Coesão:** pontos do mesmo grupo bem próximos entre si.
- **Separação:** grupos distintos bem afastados.

*Analogia:* uma festa de amigos. Cada rodinha de conversa deve ser unida (coesão) e as rodinhas devem estar distantes umas das outras para não se misturarem (separação).

### 7.3.2 O coeficiente de silhueta

Proposto por Rousseeuw (1987), é a medida interna mais popular. Para cada ponto *i*:

- **a(i):** distância média de *i* aos outros pontos **do seu grupo** (coesão).
- **b(i):** menor distância média de *i* aos pontos de **outro grupo** (o grupo vizinho mais próximo).

$$ s(i) = ( b(i) − a(i) ) / max( a(i), b(i) ) $$

O valor fica entre −1 e 1.

- **Perto de 1:** o ponto está bem encaixado no seu grupo.
- **Perto de 0:** o ponto está na fronteira entre dois grupos.
- **Negativo:** o ponto provavelmente está no grupo errado.

A **silhueta média** resume o agrupamento. Valores acima de 0,5 costumam indicar estrutura razoável; abaixo de 0,25, estrutura fraca (Kaufman; Rousseeuw, 1990).

:::atencao Silhueta alta não garante grupos úteis
Quando há valores extremos, o K-means pode isolar alguns outliers em grupos minúsculos e colocar quase todos os pontos em um só grupo gigante. A silhueta média desse resultado pode ser altíssima (acima de 0,9), embora ele não tenha utilidade nenhuma. Sempre olhe os **tamanhos dos grupos**, os perfis e a estabilidade. Você verá um caso real disso no projeto do Capítulo 2.
:::

![f7_silhueta](Figura 7.3 — Gráfico de silhueta para k = 3 e k = 5. Barras largas e longas indicam grupos coesos; barras que cruzam a linha vermelha (média) ou ficam negativas indicam problemas.)

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, silhouette_samples

X, _ = make_blobs(n_samples=500, centers=4, random_state=8)

for k in range(2, 8):
    rot = KMeans(n_clusters=k, n_init=10, random_state=0).fit_predict(X)
    print(f"k={k}  silhueta média = {silhouette_score(X, rot):.3f}")

# Silhueta individual de cada ponto
rot = KMeans(n_clusters=4, n_init=10, random_state=0).fit_predict(X)
s = silhouette_samples(X, rot)
print("Pontos com silhueta negativa:", (s < 0).sum())
```

### 7.3.3 Índice de Calinski-Harabasz

Razão entre a dispersão **entre** os grupos e a dispersão **dentro** dos grupos, ajustada pelo número de grupos e de pontos (Calinski; Harabasz, 1974).

- **Quanto maior, melhor.**
- Tende a favorecer grupos esféricos e compactos.

### 7.3.4 Índice de Davies-Bouldin

Para cada grupo, procura o grupo "mais parecido" e mede a razão entre a soma das dispersões e a distância entre os centros. Depois faz a média (Davies; Bouldin, 1979).

- **Quanto menor, melhor** (zero é o ideal).

### 7.3.5 Índice de Dunn

Razão entre a menor distância entre grupos e o maior diâmetro de um grupo (Dunn, 1974). **Quanto maior, melhor.** É muito sensível a outliers.

| Índice | Melhor valor | O que mede | Limitação |
|---|---|---|---|
| Silhueta | Alto (→ 1) | Encaixe de cada ponto | Favorece grupos convexos |
| Calinski-Harabasz | Alto | Razão entre/dentro | Favorece grupos esféricos |
| Davies-Bouldin | Baixo (→ 0) | Similaridade entre grupos | Favorece grupos esféricos |
| Dunn | Alto | Separação/diâmetro | Sensível a outliers |

:::atencao Índices internos têm viés
Quase todos presumem grupos **convexos e compactos**. Eles podem punir injustamente o resultado correto do DBSCAN em luas ou anéis. Para métodos baseados em densidade, o índice **DBCV** (Moulavi et al., 2014) é mais adequado.
:::

```python
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import calinski_harabasz_score, davies_bouldin_score, silhouette_score

X, _ = make_blobs(n_samples=500, centers=4, random_state=8)
print(" k  silhueta   CH       DB")
for k in range(2, 8):
    r = KMeans(n_clusters=k, n_init=10, random_state=0).fit_predict(X)
    sil = silhouette_score(X, r)
    ch = calinski_harabasz_score(X, r)
    db = davies_bouldin_score(X, r)
    print(f"{k:2d}  {sil:7.3f}  {ch:8.1f}  {db:6.3f}")
```

![f7_indices](Figura 7.4 — Os três índices em função de k. Quando concordam (aqui, em k = 4), ganhamos confiança na escolha.)

## 7.4 Escolhendo k de modo mais rigoroso

### 7.4.1 A estatística gap

Tibshirani, Walther e Hastie (2001) propuseram comparar a inércia observada com a esperada se os dados fossem **uniformes** (sem grupos):

$$ Gap(k) = E[ log W_k (dados de referência) ] − log W_k (dados observados) $$

Escolhe-se o menor *k* tal que Gap(*k*) ≥ Gap(*k*+1) − desvio padrão do Gap(*k*+1).

![f7_gap](Figura 7.5 — Estatística gap: o primeiro k que satisfaz o critério é a escolha.)

### 7.4.2 Estabilidade

Se os grupos são "reais", eles devem **resistir a pequenas perturbações**. Teste:

1. Sorteie várias subamostras (*bootstrap*).
2. Agrupe cada uma.
3. Compare os resultados entre si (com o ARI, a seguir).
4. Se a concordância é alta, o agrupamento é **estável** (Ben-Hur; Elisseeff; Guyon, 2002; Lange et al., 2004).

![f7_estabilidade](Figura 7.6 — Estabilidade: para o k correto, as repetições concordam entre si; para k errado, os resultados variam.)

```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import adjusted_rand_score

X, _ = make_blobs(n_samples=600, centers=4, random_state=8)
rng = np.random.default_rng(0)

def estabilidade(k, repeticoes=20):
    scores = []
    for _ in range(repeticoes):
        i1 = rng.choice(len(X), len(X) // 2, replace=False)
        i2 = rng.choice(len(X), len(X) // 2, replace=False)
        m1 = KMeans(k, n_init=5, random_state=0).fit(X[i1])
        m2 = KMeans(k, n_init=5, random_state=1).fit(X[i2])
        # Compara as duas soluções no conjunto inteiro
        scores.append(adjusted_rand_score(m1.predict(X), m2.predict(X)))
    return np.mean(scores)

for k in range(2, 8):
    print(f"k={k}  estabilidade (ARI médio) = {estabilidade(k):.3f}")
```

## 7.5 Validação externa: quando há um gabarito

Às vezes temos rótulos de referência, por exemplo em conjuntos de pesquisa, e queremos saber **o quanto o agrupamento os reproduz**. Atenção: os números dos grupos são arbitrários. "Grupo 0" pode ser a "Classe B". Por isso as medidas devem ser **invariantes à troca de nomes**.

### 7.5.1 Matriz de contingência

É uma tabela que cruza grupos (linhas) e classes (colunas), contando quantos pontos de cada classe caíram em cada grupo.

| | Classe A | Classe B | Classe C |
|---|---|---|---|
| **Grupo 0** | 48 | 2 | 0 |
| **Grupo 1** | 1 | 45 | 6 |
| **Grupo 2** | 1 | 3 | 44 |

![f7_contingencia](Figura 7.7 — Matriz de contingência como mapa de calor: uma diagonal forte indica boa concordância.)

### 7.5.2 Pureza

Para cada grupo, conte a classe majoritária. Some e divida pelo total. Vai de 0 a 1. Defeito: cresce com o número de grupos (com *n* grupos, a pureza é 1).

### 7.5.3 Índice de Rand e Rand ajustado (ARI)

O **Rand** conta pares de pontos em que os dois agrupamentos **concordam** (juntos nos dois, ou separados nos dois). O **Rand ajustado (ARI)** desconta a concordância esperada ao acaso (Hubert; Arabie, 1985).

- **ARI = 1:** concordância perfeita.
- **ARI ≈ 0:** concordância ao nível do acaso.
- **ARI < 0:** pior que o acaso.

### 7.5.4 Informação mútua normalizada (NMI)

Vem da teoria da informação. Mede quanta informação sobre um agrupamento obtemos ao conhecer o outro, normalizada entre 0 e 1 (Strehl; Ghosh, 2002; Vinh; Epps; Bailey, 2010).

### 7.5.5 Homogeneidade, completude e V-measure

- **Homogeneidade:** cada grupo contém membros de uma única classe.
- **Completude:** todos os membros de uma classe estão no mesmo grupo.
- **V-measure:** média harmônica das duas (Rosenberg; Hirschberg, 2007).

```python
from sklearn.datasets import load_iris
from sklearn.cluster import KMeans, AgglomerativeClustering
from sklearn.metrics import (adjusted_rand_score, normalized_mutual_info_score,
                             homogeneity_completeness_v_measure)

X, y = load_iris(return_X_y=True)
for nome, modelo in [("K-means", KMeans(3, n_init=10, random_state=0)),
                     ("Ward   ", AgglomerativeClustering(3, linkage="ward"))]:
    r = modelo.fit_predict(X)
    h, c, v = homogeneity_completeness_v_measure(y, r)
    print(f"{nome} ARI={adjusted_rand_score(y, r):.3f}  "
          f"NMI={normalized_mutual_info_score(y, r):.3f}  "
          f"H={h:.3f} C={c:.3f} V={v:.3f}")
```

:::saibamais Um aviso de Von Luxburg e colegas
Von Luxburg, Williamson e Guyon (2012) lembram que "clustering" não tem uma definição única. A melhor solução depende do **objetivo** de quem agrupa. Rótulos de referência nem sempre representam o agrupamento "correto"; apenas um deles possível.
:::

## 7.6 Validação pelo uso e pela interpretação

Nenhum número substitui estas perguntas:

- Os grupos fazem **sentido para o especialista**?
- São **acionáveis**? Cada grupo recebe uma ação diferente?
- Têm **tamanho útil**? Um grupo de 3 clientes dificilmente justifica uma campanha.
- São **estáveis** no tempo e entre amostras?
- Diferem de modo **relevante** nas variáveis de negócio (que não entraram no agrupamento)?

### 7.6.1 Perfil dos grupos

Uma boa prática é construir uma **tabela de perfil**: a média (ou mediana) de cada atributo, por grupo, e compará-la com a média geral. Gráficos de radar e de barras ajudam a contar a história.

```python
import pandas as pd
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

dados = load_wine(as_frame=True)
X = dados.data[["alcohol", "malic_acid", "flavanoids", "color_intensity"]]
grupos = KMeans(3, n_init=10, random_state=0).fit_predict(StandardScaler().fit_transform(X))

perfil = X.assign(grupo=grupos).groupby("grupo").mean()
relativo = (perfil / X.mean()).round(2)      # >1: acima da média geral
print(relativo)
```

## 7.7 Um roteiro prático de avaliação

1. **Hopkins:** há tendência de agrupamento?
2. **Varie *k*** (ou os parâmetros) e calcule silhueta, CH, DB e gap.
3. **Teste a estabilidade** com reamostragens.
4. **Compare algoritmos** (K-means, hierárquico, GMM, DBSCAN).
5. **Visualize** (Capítulos 8 e 9).
6. **Perfile** os grupos e valide com especialistas.
7. **Documente** as escolhas e os critérios.

:::dica Se os critérios discordarem
É normal. Prefira o *k* em que **vários** critérios concordam, a solução **estável** e a que tenha **melhor interpretação**.
:::

## Resumo do capítulo

:::memorize Cartões de memorização
- **Sem gabarito**, avaliar exige critérios internos, relativos e externos.
- **Hopkins:** os dados têm grupos para encontrar?
- **Silhueta** (−1 a 1): quanto maior, melhor encaixe.
- **Calinski-Harabasz:** maior é melhor. **Davies-Bouldin:** menor é melhor.
- **Gap** e **estabilidade** ajudam a escolher *k*.
- **ARI e NMI** comparam com rótulos de referência e ignoram os nomes dos grupos.
- **Interpretação e utilidade** têm a palavra final.
:::
