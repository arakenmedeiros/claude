## 5.1 Ilhas e oceano

Olhe um mapa-múndi à noite, com as luzes das cidades. Você enxerga "manchas" brilhantes (cidades) separadas por áreas escuras. Nenhuma regra manda contar "3 manchas". Seus olhos simplesmente percebem **regiões densas** cercadas por **regiões vazias**.

Essa é a ideia do **agrupamento por densidade**:

> Um grupo é uma região onde os pontos estão **bem próximos uns dos outros**, separada de outros grupos por regiões **pouco povoadas**.

Consequências importantes:

- Os grupos podem ter **qualquer forma** (luas, espirais, anéis).
- Não é preciso fixar o número de grupos.
- Pontos isolados são tratados como **ruído**, e não forçados a entrar em algum grupo.

![f5_ilhas](Figura 5.1 — Cidades à noite: grupos são regiões densas, separadas por vazio. O ruído são luzes isoladas.)

## 5.2 O DBSCAN

O **DBSCAN** (*Density-Based Spatial Clustering of Applications with Noise*) foi proposto por Ester, Kriegel, Sander e Xu (1996) e é um dos algoritmos de agrupamento mais citados da história. Em 2014, o artigo recebeu um prêmio de "teste do tempo" da conferência KDD.

### 5.2.1 Os dois parâmetros

- **eps (ε):** o raio da "vizinhança". Pense num círculo de ε de raio desenhado em volta de cada ponto.
- **min_samples (MinPts):** o número mínimo de pontos (incluindo o próprio) dentro desse círculo para a região ser considerada "densa".

### 5.2.2 Os três tipos de ponto

- **Ponto central (*core*):** tem pelo menos `min_samples` pontos no raio ε. Está "no coração" de uma região densa.
- **Ponto de borda (*border*):** não é central, mas está dentro do raio ε de algum ponto central. Fica na "praia" do grupo.
- **Ruído (*noise*):** não é central nem de borda. É um ponto solitário.

![f5_conceitos](Figura 5.2 — Pontos centrais (azul), de borda (laranja) e ruído (vermelho), com min_samples = 4. Os círculos têm raio eps.)

### 5.2.3 Alcançabilidade e conectividade

- Um ponto *q* é **diretamente alcançável por densidade** a partir de um ponto central *p* se *q* está no raio ε de *p*.
- Pontos centrais que estão no raio um do outro formam uma **cadeia**. Um grupo é uma cadeia máxima de pontos centrais, mais suas bordas.

*Analogia:* um boato que passa de pessoa a pessoa. Se você é "central" (tem pelo menos *m* amigos próximos), o boato passa a eles. Quem está na periferia ouve o boato, mas não o repassa.

### 5.2.4 O algoritmo em palavras

1. Escolha um ponto ainda não visitado.
2. Se ele é central, crie um novo grupo e **expanda**: adicione todos os vizinhos; para cada vizinho que também é central, adicione os vizinhos dele, e assim por diante.
3. Se não é central, marque-o temporariamente como ruído (ele ainda pode virar borda de algum grupo depois).
4. Repita até visitar todos.

## 5.3 DBSCAN no Python

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.cluster import DBSCAN, KMeans
from sklearn.preprocessing import StandardScaler

X, _ = make_moons(n_samples=400, noise=0.07, random_state=0)
X = StandardScaler().fit_transform(X)

db = DBSCAN(eps=0.3, min_samples=5).fit(X)
rotulos = db.labels_                    # -1 significa ruído

n_grupos = len(set(rotulos)) - (1 if -1 in rotulos else 0)
print("Grupos encontrados:", n_grupos)
print("Pontos de ruído   :", (rotulos == -1).sum())

# Comparação com K-means
km = KMeans(n_clusters=2, n_init=10, random_state=0).fit_predict(X)

fig, ax = plt.subplots(1, 2, figsize=(9, 4))
ax[0].scatter(*X.T, c=km, s=15);      ax[0].set_title("K-means")
ax[1].scatter(*X.T, c=rotulos, s=15); ax[1].set_title("DBSCAN")
plt.show()
```

**Como interpretar:**

- `labels_` guarda o grupo de cada ponto. O valor **−1** marca ruído.
- `core_sample_indices_` lista os pontos centrais.
- O K-means corta as luas ao meio. O DBSCAN as separa corretamente.

![f5_vs_kmeans](Figura 5.3 — Em formas não convexas, o DBSCAN acerta onde o K-means falha.)

## 5.4 Como escolher eps e min_samples?

### 5.4.1 Regra para min_samples

Uma regra comum: `min_samples` ≥ *d* + 1, onde *d* é o número de atributos. Para dados com muito ruído, aumente o valor. Em duas dimensões, valores entre 4 e 10 costumam funcionar (Schubert et al., 2017).

### 5.4.2 O gráfico de k-distâncias

Para escolher eps:

1. Para cada ponto, calcule a distância até seu *k*-ésimo vizinho mais próximo (com *k* = `min_samples`).
2. Ordene essas distâncias em ordem crescente e faça o gráfico.
3. Procure o **joelho** da curva. O valor de y nesse ponto é um bom candidato a eps.

*Intuição:* pontos dentro de grupos têm vizinhos próximos (parte baixa da curva). Pontos de ruído têm vizinhos distantes (subida acentuada).

![f5_kdist](Figura 5.4 — Gráfico de k-distâncias: o joelho sugere o valor de eps.)

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.neighbors import NearestNeighbors
from sklearn.datasets import make_moons
from sklearn.preprocessing import StandardScaler

X = StandardScaler().fit_transform(make_moons(400, noise=0.07, random_state=0)[0])
k = 5
vizinhos = NearestNeighbors(n_neighbors=k).fit(X)
dist, _ = vizinhos.kneighbors(X)
dk = np.sort(dist[:, -1])               # distância ao k-ésimo vizinho

plt.plot(dk)
plt.xlabel("Pontos ordenados")
plt.ylabel(f"Distância ao {k}º vizinho")
plt.show()
```

### 5.4.3 Efeitos de eps

- **eps pequeno demais:** quase tudo vira ruído; muitos micro-grupos.
- **eps grande demais:** grupos distintos se fundem num só.

:::atencao Escale os dados!
Como o DBSCAN usa um raio único, todos os atributos precisam estar na mesma escala. Padronize antes (Capítulo 2).
:::

## 5.5 Pontos fortes e fracos do DBSCAN

**Pontos fortes**

- Descobre grupos de **formas arbitrárias**.
- **Detecta ruído** naturalmente.
- Não exige *k*.
- Eficiente: O(*n* log *n*) com índices espaciais.

**Pontos fracos**

- **Densidade única.** Com um só eps, não lida bem com grupos de densidades muito diferentes.
- **Sensível aos parâmetros.**
- **Alta dimensão:** o conceito de "vizinhança" perde sentido (Capítulo 2).
- Pontos de borda podem ser atribuídos a grupos diferentes dependendo da ordem de visita.

![f5_densidades](Figura 5.5 — O problema das densidades variáveis: um eps que funciona para o grupo denso transforma o grupo difuso em ruído.)

## 5.6 OPTICS: a ordenação por alcançabilidade

O **OPTICS** (Ankerst et al., 1999) resolve a questão das densidades variáveis. Em vez de fornecer *uma* partição, ele produz uma **ordem dos pontos** e, para cada um, uma **distância de alcançabilidade**.

Ao desenhar essas distâncias na ordem calculada, obtém-se o **gráfico de alcançabilidade**.

- **Vales** = regiões densas = grupos.
- **Picos** = fronteiras entre grupos.
- Vales profundos são grupos bem densos; vales rasos, grupos difusos.

*Analogia:* uma paisagem de relevo. Os vales são cidades; as serras entre eles, áreas vazias. Você escolhe onde "alagar" para definir os grupos.

![f5_optics](Figura 5.6 — Gráfico de alcançabilidade do OPTICS: cada vale corresponde a um grupo, com densidades diferentes.)

```python
from sklearn.cluster import OPTICS
from sklearn.datasets import make_blobs
import numpy as np

# Três grupos com densidades bem diferentes
X1, _ = make_blobs(200, centers=[[0, 0]],  cluster_std=0.3, random_state=0)
X2, _ = make_blobs(200, centers=[[4, 4]],  cluster_std=1.0, random_state=1)
X3, _ = make_blobs(200, centers=[[-4, 4]], cluster_std=0.6, random_state=2)
X = np.vstack([X1, X2, X3])

op = OPTICS(min_samples=10, xi=0.05, min_cluster_size=0.05).fit(X)
print("Grupos:", len(set(op.labels_)) - (1 if -1 in op.labels_ else 0))
print("Ruído :", (op.labels_ == -1).sum())
# op.reachability_[op.ordering_] contém a curva do gráfico de alcançabilidade
```

## 5.7 HDBSCAN: densidade hierárquica

O **HDBSCAN** (Campello; Moulavi; Sander, 2013) combina duas ideias: densidade (como o DBSCAN) e hierarquia (como o Capítulo 4).

Em linhas gerais:

1. Calcula uma **distância de alcançabilidade mútua**, que "afasta" pontos em regiões esparsas.
2. Constrói a **árvore geradora mínima** e a transforma numa hierarquia (um dendrograma).
3. **Condensa** a árvore, descartando divisões que separam grupos minúsculos.
4. Escolhe os grupos **mais estáveis**: aqueles que "sobrevivem" por uma ampla faixa de valores de densidade.

**Vantagens sobre o DBSCAN:**

- Funciona com **densidades variáveis**.
- Só exige `min_cluster_size` (intuitivo: "qual o menor grupo que me interessa?").
- Fornece uma **probabilidade** de pertinência por ponto.

```python
from sklearn.cluster import HDBSCAN
from sklearn.datasets import make_blobs
import numpy as np

X1, _ = make_blobs(200, centers=[[0, 0]],  cluster_std=0.3, random_state=0)
X2, _ = make_blobs(200, centers=[[4, 4]],  cluster_std=1.0, random_state=1)
X = np.vstack([X1, X2])

h = HDBSCAN(min_cluster_size=20).fit(X)
print("Grupos:", len(set(h.labels_)) - (1 if -1 in h.labels_ else 0))
print("Ruído :", (h.labels_ == -1).sum())
print("Probabilidades (5 primeiros):", h.probabilities_[:5].round(2))
```

:::saibamais Disponibilidade
O HDBSCAN passou a integrar o scikit-learn a partir da versão 1.3. Antes disso, era distribuído no pacote independente `hdbscan` (McInnes; Healy; Astels, 2017).
:::

## 5.8 Outras ideias de densidade

- **Mean-shift** (Comaniciu; Meer, 2002): cada ponto "escala o morro" da densidade estimada até um pico. Os picos são os centros dos grupos. Não exige *k*.
- **DENCLUE:** modela a densidade como soma de funções de influência.
- **Grades de densidade (CLIQUE, STING):** dividem o espaço em células e unem as densas.

## 5.9 Estudo de caso: pontos de táxi em uma cidade

Imagine milhares de coordenadas (latitude e longitude) de embarque de passageiros. Queremos achar os **pontos quentes** (aeroportos, estações, bairros boêmios).

Por que DBSCAN (ou HDBSCAN) e não K-means?

- Os pontos quentes têm formas irregulares (seguem ruas e avenidas).
- Existem embarques isolados que são ruído, e não "pontos quentes".
- Não sabemos quantos pontos quentes existem.

Em geografia, usa-se a distância **haversine**, que mede distância sobre a esfera terrestre.

```python
import numpy as np
from sklearn.cluster import DBSCAN

rng = np.random.default_rng(0)
# Coordenadas simuladas (graus): 3 pontos quentes + ruído espalhado
centros = np.array([[-23.55, -46.63], [-23.43, -46.47], [-23.62, -46.70]])
pts = np.vstack([c + rng.normal(0, 0.005, (150, 2)) for c in centros])
ruido = np.column_stack([rng.uniform(-23.7, -23.4, 60), rng.uniform(-46.8, -46.4, 60)])
coords = np.vstack([pts, ruido])

rad = np.radians(coords)
raio_terra_km = 6371.0
eps_km = 0.5                              # 500 metros
db = DBSCAN(eps=eps_km / raio_terra_km, min_samples=10,
            metric="haversine", algorithm="ball_tree").fit(rad)

print("Pontos quentes:", len(set(db.labels_)) - (1 if -1 in db.labels_ else 0))
print("Ruído:", (db.labels_ == -1).sum())
```

## 5.10 Comparando os métodos

| Critério | K-means | DBSCAN | OPTICS | HDBSCAN |
|---|---|---|---|---|
| Precisa de *k*? | Sim | Não | Não | Não |
| Forma dos grupos | Esférica | Qualquer | Qualquer | Qualquer |
| Densidades variáveis | Não se aplica | Fraco | Bom | Muito bom |
| Detecta ruído? | Não | Sim | Sim | Sim |
| Parâmetros-chave | *k* | eps, min_samples | min_samples, xi | min_cluster_size |
| Escalabilidade | Excelente | Boa | Média | Boa |

:::memorize Cartões de memorização
- **Grupo = região densa** separada por regiões vazias.
- **DBSCAN:** eps (raio) e min_samples (mínimo de vizinhos).
- **Central, borda, ruído.** Rótulo −1 = ruído.
- **Gráfico de k-distâncias** → joelho → eps.
- **Fraqueza:** densidades variáveis e alta dimensão.
