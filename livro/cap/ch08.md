## 8.1 Por que reduzir dimensões?

Uma foto 28 × 28 tem 784 números. Um genoma tem milhares de genes. Um texto pode ter 50 mil palavras possíveis. São dados de **alta dimensão**.

Reduzir dimensões ajuda a:

1. **Visualizar.** Só enxergamos 2D ou 3D.
2. **Acelerar** algoritmos e economizar memória.
3. **Eliminar ruído e redundância.**
4. **Combater a maldição da dimensionalidade** (Capítulo 2).
5. **Entender** quais combinações de atributos importam.

### 8.1.1 Seleção versus extração

- **Seleção de atributos:** escolhe um subconjunto das colunas originais e descarta o resto. Mantém a interpretação.
- **Extração de atributos:** cria **novas colunas** como combinações das originais. É o caso do PCA.

*Analogia:* numa receita com 20 ingredientes, a **seleção** tira 8 ingredientes. A **extração** cria "misturas prontas" (ex.: "tempero base") que resumem vários ingredientes.

## 8.2 A intuição do PCA

A **Análise de Componentes Principais** (PCA) foi proposta por Pearson (1901) e desenvolvida por Hotelling (1933). Ainda hoje é a técnica de redução mais usada (Jolliffe; Cadima, 2016).

### 8.2.1 A analogia da sombra

Segure um objeto 3D diante de uma lâmpada. A sombra na parede é 2D. Dependendo do **ângulo**, a sombra revela muito ou pouco do objeto. Uma sombra de um lápis visto de frente é só um pontinho. De lado, mostra seu comprimento.

O PCA procura o **melhor ângulo de iluminação**: aquele cuja sombra preserva o máximo da informação do objeto.

![f8_sombra](Figura 8.1 — Sombras: o mesmo objeto 3D projetado de ângulos diferentes. O PCA escolhe o ângulo que preserva mais informação.)

### 8.2.2 Informação = variância

No PCA, "informação" significa **variância**: o quanto os dados se espalham. Um atributo que varia pouco quase não ajuda a distinguir exemplos. Um que varia muito, ajuda.

O PCA procura **direções** (eixos novos) nas quais os dados têm **máxima variância**:

- **PC1 (primeira componente principal):** a direção de maior variância.
- **PC2:** a direção de maior variância entre as **perpendiculares** a PC1.
- **PC3:** perpendicular às duas anteriores, e assim por diante.

![f8_pca_intuicao](Figura 8.2 — PC1 aponta para onde a nuvem mais se estende. PC2 é perpendicular. Projetar nos eixos novos "gira" a nuvem.)

:::memorize PCA em uma frase
Girar os eixos para alinhá-los às direções de maior espalhamento e ficar só com os primeiros.
:::

## 8.3 Como o PCA funciona, passo a passo

1. **Centralize** os dados: subtraia a média de cada coluna. (Padronize também, se as escalas forem diferentes.)
2. **Calcule a matriz de covariância** C. Ela mostra como os atributos variam juntos.
3. **Calcule autovalores e autovetores** de C.
   - Cada **autovetor** é uma direção (um eixo novo).
   - Cada **autovalor** é a variância dos dados ao longo daquele eixo.
4. **Ordene** os autovetores do maior para o menor autovalor.
5. **Escolha** os *k* primeiros: eles formam uma matriz W de projeção.
6. **Projete:** os novos dados são Z = X_centralizado × W.

### 8.3.1 Um exemplo mínimo

Dois atributos: altura e peso de 5 pessoas (já centralizados):

| Pessoa | Altura | Peso |
|---|---|---|
| 1 | −2 | −3 |
| 2 | −1 | −1 |
| 3 | 0 | 0 |
| 4 | 1 | 2 |
| 5 | 2 | 2 |

Os dados formam uma nuvem alongada, subindo da esquerda para a direita. O PC1 aponta nessa direção e combina altura e peso. O PC2 aponta na perpendicular e captura as pequenas diferenças restantes. Provavelmente PC1 explicará mais de 95 % da variância: **um único número** (a posição ao longo de PC1) resume bem cada pessoa.

## 8.4 A relação com a SVD

A **Decomposição em Valores Singulares** (SVD) fatora qualquer matriz X em três:

$$ X = U · S · Vᵀ $$

- **V:** as direções principais (autovetores da covariância).
- **S:** valores singulares (relacionados aos autovalores: autovalor = s² / (n − 1)).
- **U·S:** os escores (dados projetados).

Na prática, o scikit-learn calcula o PCA via SVD, que é mais estável e rápida. Um resultado clássico (Eckart; Young, 1936) garante que truncar a SVD nos *k* maiores valores singulares dá a **melhor aproximação de posto *k*** da matriz, no sentido dos mínimos quadrados.

## 8.5 PCA no Python

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

X, y = load_iris(return_X_y=True)
Xp = StandardScaler().fit_transform(X)

pca = PCA(n_components=4).fit(Xp)

print("Variância explicada   :", pca.explained_variance_ratio_.round(3))
print("Variância acumulada   :", pca.explained_variance_ratio_.cumsum().round(3))
print("Cargas (componentes):\n", pca.components_.round(2))

Z = PCA(n_components=2).fit_transform(Xp)
plt.scatter(Z[:, 0], Z[:, 1], c=y)
plt.xlabel("PC1"); plt.ylabel("PC2"); plt.title("Iris em 2 componentes")
plt.show()
```

**Como ler a saída:**

- `explained_variance_ratio_`: a fração da variância total que cada componente explica.
- `components_`: cada linha é uma componente, com **cargas** (*loadings*), o peso de cada atributo original.
- No Iris, as duas primeiras componentes retêm cerca de 96 % da variância.

## 8.6 Quantas componentes manter?

### 8.6.1 Variância acumulada

Some a variância explicada das componentes em ordem. Escolha o menor número que atinja um limiar, como **90 % ou 95 %**.

```python
from sklearn.decomposition import PCA
# Pede ao PCA o nº de componentes suficiente para 95% da variância
pca95 = PCA(n_components=0.95)
```

### 8.6.2 Gráfico *scree* (de declive)

Desenhe a variância de cada componente. Procure o "cotovelo": a partir dele, as componentes acrescentam pouco (Cattell, 1966).

![f8_scree](Figura 8.3 — Gráfico scree e variância acumulada: o cotovelo e a linha de 95 %.)

### 8.6.3 Critério de Kaiser

Com dados padronizados, mantenha componentes com autovalor maior que 1: cada uma explica mais que um atributo original sozinho (Kaiser, 1960). Regra simples, mas discutível.

### 8.6.4 Validação cruzada e análise paralela

A **análise paralela** (Horn, 1965) compara os autovalores reais com os obtidos em dados aleatórios de mesmo tamanho. Mantém-se apenas o que supera o acaso. É considerada mais confiável que Kaiser.

## 8.7 Interpretando o resultado

### 8.7.1 Escores e cargas

- **Escores (*scores*):** as novas coordenadas de cada exemplo.
- **Cargas (*loadings*):** o quanto cada atributo original contribui para cada componente.

### 8.7.2 O biplot

O **biplot** (Gabriel, 1971) mostra num só gráfico os exemplos (pontos) e os atributos (setas). Setas que apontam para a mesma direção estão correlacionadas. Setas perpendiculares são independentes. Setas opostas, anticorrelacionadas.

![f8_biplot](Figura 8.4 — Biplot do conjunto Iris: pontos são flores; setas, os atributos.)

:::atencao Cuidado
Os sinais das componentes são arbitrários: multiplicar uma componente por −1 não muda nada. E as componentes são combinações de *todos* os atributos, o que dificulta a explicação para leigos.
:::

## 8.8 PCA para reconstruir e comprimir

Podemos voltar ao espaço original com `inverse_transform`. A imagem reconstruída com poucas componentes perde detalhes, mas guarda o essencial.

![f8_digitos](Figura 8.5 — Dígitos manuscritos reconstruídos com 2, 5, 15 e 40 componentes. Com 15 já reconhecemos os números.)

```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA

X, y = load_digits(return_X_y=True)          # 1797 imagens de 8x8 = 64 atributos
print("Original:", X.shape)

for k in [2, 5, 15, 40]:
    pca = PCA(n_components=k).fit(X)
    Xr = pca.inverse_transform(pca.transform(X))
    erro = np.mean((X - Xr) ** 2)
    var = pca.explained_variance_ratio_.sum()
    print(f"{k:3d} componentes -> variância {var:.2%}  erro quadrático médio {erro:.2f}")
```

### 8.8.1 Remoção de ruído

Se o ruído é aleatório e a informação está concentrada em poucas direções, descartar as componentes de baixa variância **limpa** a imagem.

## 8.9 Pontos de atenção do PCA

- **Linear:** captura apenas relações lineares. Para estruturas curvas, veja o Capítulo 9.
- **Sensível à escala:** padronize.
- **Sensível a outliers:** eles puxam as direções. Há versões robustas (*Robust PCA*).
- **Variância ≠ importância:** uma direção de pouca variância pode separar classes importantes.
- **Sem rótulos:** não sabe nada sobre classes.

## 8.10 Variações do PCA

### 8.10.1 PCA incremental

Para bases que não cabem na memória, processa os dados em lotes.

```python
import numpy as np
from sklearn.decomposition import IncrementalPCA

rng = np.random.default_rng(0)
ipca = IncrementalPCA(n_components=5, batch_size=500)
for _ in range(10):                      # simula 10 lotes lidos do disco
    lote = rng.normal(size=(500, 50))
    ipca.partial_fit(lote)
print(ipca.explained_variance_ratio_.round(3))
```

### 8.10.2 PCA aleatorizado

Para matrizes enormes, algoritmos aleatórios aproximam a SVD com grande economia de tempo (Halko; Martinsson; Tropp, 2011). No scikit-learn: `PCA(svd_solver="randomized")`.

### 8.10.3 PCA esparso

Força muitas cargas a serem **zero**, de modo que cada componente envolva poucos atributos. Fica mais interpretável (Zou; Hastie; Tibshirani, 2006).

### 8.10.4 PCA com kernel

O **Kernel PCA** (Schölkopf; Smola; Müller, 1998) usa uma função *kernel* para fazer, implicitamente, o PCA num espaço de dimensão muito maior, onde relações não lineares viram lineares. Funciona bem para anéis e espirais.

```python
import numpy as np
from sklearn.datasets import make_circles
from sklearn.decomposition import PCA, KernelPCA

X, y = make_circles(n_samples=400, factor=0.3, noise=0.03, random_state=0)
Z_lin = PCA(2).fit_transform(X)
Z_rbf = KernelPCA(n_components=2, kernel="rbf", gamma=10).fit_transform(X)

# No PCA linear os dois anéis continuam misturados na 1ª componente;
# no Kernel PCA a 1ª componente já separa os anéis.
lin_int, lin_ext = Z_lin[y == 1, 0].mean(), Z_lin[y == 0, 0].mean()
rbf_int, rbf_ext = Z_rbf[y == 1, 0].mean(), Z_rbf[y == 0, 0].mean()
print("PC1 linear: anel interno", round(lin_int, 2), "| externo", round(lin_ext, 2))
print("PC1 kernel: anel interno", round(rbf_int, 2), "| externo", round(rbf_ext, 2))
```

## 8.11 Análise de Componentes Independentes (ICA)

### 8.11.1 O problema da festa (*cocktail party*)

Numa festa, dois microfones gravam a mistura de duas pessoas falando ao mesmo tempo. Como **separar** cada voz sem saber como a mistura foi feita? Esse é o problema da **separação cega de fontes**.

![f8_ica](Figura 8.6 — Cocktail party: duas fontes independentes são misturadas em dois microfones. O ICA recupera as fontes originais; o PCA não.)

### 8.11.2 A ideia

- **PCA** busca componentes **não correlacionadas**.
- **ICA** busca componentes **estatisticamente independentes**, um critério mais forte (Hyvärinen; Oja, 2000).

O ICA explora o fato de que sinais independentes e não gaussianos, quando somados, ficam "mais gaussianos" (pelo Teorema Central do Limite). O algoritmo procura direções que **maximizam a não gaussianidade**. O algoritmo FastICA é o mais popular.

```python
import numpy as np
from sklearn.decomposition import FastICA, PCA

t = np.linspace(0, 8, 2000)
s1 = np.sin(2 * t)                       # fonte 1: senoide
s2 = np.sign(np.sin(3 * t))              # fonte 2: onda quadrada
S = np.c_[s1, s2] + 0.05 * np.random.default_rng(0).normal(size=(2000, 2))

A = np.array([[1.0, 0.5], [0.4, 1.0]])   # mistura desconhecida
X = S @ A.T                              # sinais "gravados"

S_ica = FastICA(n_components=2, random_state=0).fit_transform(X)
S_pca = PCA(n_components=2).fit_transform(X)

# Correlação absoluta entre cada fonte original e cada componente recuperada
def melhor(S, R):
    c = np.abs(np.corrcoef(S.T, R.T)[:2, 2:])
    return c.max(axis=1).round(2)

print("ICA recupera as fontes? ", melhor(S, S_ica))
print("PCA recupera as fontes? ", melhor(S, S_pca))
```

**Aplicações:** separação de vozes, remoção de artefatos (piscadas) em eletroencefalogramas e análise de imagens cerebrais.

## 8.12 Fatoração de Matrizes Não Negativas (NMF)

### 8.12.1 A ideia: montar com peças

Muitos dados são naturalmente **não negativos**: pixels, contagens de palavras, notas de produtos. O **NMF** decompõe uma matriz X (não negativa) como o produto de duas matrizes também não negativas (Lee; Seung, 1999):

$$ X ≈ W · H $$

- **H:** as "peças" básicas (partes de rostos, tópicos de texto).
- **W:** quanto de cada peça cada exemplo usa.

Como tudo é **aditivo** (não há subtração), as peças tendem a ser **partes** interpretáveis. Lee e Seung (1999) mostraram que, ao aplicar o NMF a rostos, as peças aprendidas eram olhos, narizes e bocas, enquanto o PCA gerava "rostos fantasmas" globais.

![f8_nmf](Figura 8.7 — NMF aprende partes (traços de dígitos); o PCA aprende padrões globais com valores positivos e negativos.)

*Analogia:* o NMF é como montar um desenho com adesivos. Você só pode **adicionar** adesivos, nunca recortar.

### 8.12.2 Aplicação em texto: descoberta de tópicos

Se X conta palavras em documentos, cada linha de H é um **tópico** (um conjunto de palavras que aparecem juntas) e W indica o quanto cada documento fala de cada tópico.

```python
from sklearn.decomposition import NMF
from sklearn.feature_extraction.text import TfidfVectorizer

docs = [
    "o time venceu o jogo com gol no final",
    "o campeonato de futebol tem jogo decisivo",
    "o banco aumentou a taxa de juros",
    "a inflação e os juros preocupam o mercado",
    "o atacante marcou gol e o time venceu",
    "o mercado reage ao aumento dos juros e da inflação",
]
vet = TfidfVectorizer()
X = vet.fit_transform(docs)

nmf = NMF(n_components=2, init="nndsvda", random_state=0, max_iter=500)
W = nmf.fit_transform(X)
H = nmf.components_

palavras = vet.get_feature_names_out()
for i, topico in enumerate(H):
    top = topico.argsort()[::-1][:5]
    print(f"Tópico {i}:", [palavras[j] for j in top])
```

## 8.13 Comparação das técnicas lineares

| Técnica | Objetivo | Restrição | Melhor para |
|---|---|---|---|
| PCA | Máxima variância | Eixos ortogonais | Resumo, visualização, compressão |
| SVD truncada | Aproximação de posto baixo | Sem centralização | Matrizes esparsas e texto (LSA) |
| ICA | Independência estatística | Fontes não gaussianas | Separação de sinais |
| NMF | Partes aditivas | Valores ≥ 0 | Imagens, texto, tópicos |
| Kernel PCA | PCA não linear | Escolha do kernel | Formas curvas |

## Resumo do capítulo

:::memorize Cartões de memorização
- **PCA:** gira os eixos para as direções de máxima variância.
- **Passos:** centralizar → covariância → autovetores → ordenar → projetar.
- **Escolha de k:** variância acumulada (90–95 %), scree, análise paralela.
- **Cargas** mostram o peso dos atributos; **escores** são as novas coordenadas.
- **SVD** é a forma numérica estável de calcular o PCA.
- **ICA:** fontes independentes. **NMF:** partes aditivas.
- O PCA é linear; para curvas, use Kernel PCA ou variedades.
:::
