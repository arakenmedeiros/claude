@@EX 1 | K-means "do zero" com NumPy | intermediário
Implemente o algoritmo de Lloyd com NumPy (sem usar `KMeans`) para dados de `make_blobs` (3 grupos). Use 20 iterações e inicialização aleatória escolhendo 3 pontos dos dados. Calcule a inércia final e compare com a do `KMeans` do scikit-learn (`n_init=1`, mesmo tipo de inicialização).

*Dica:* a atribuição usa `np.argmin` sobre as distâncias; a atualização usa a média de cada grupo.
@@SOL
```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans

X, _ = make_blobs(300, centers=3, cluster_std=1.0, random_state=7)
rng = np.random.default_rng(0)
C = X[rng.choice(len(X), 3, replace=False)]          # centros iniciais

for _ in range(20):
    D = ((X[:, None, :] - C[None, :, :]) ** 2).sum(axis=2)   # distâncias ao quadrado
    rot = D.argmin(axis=1)                                   # atribuição
    C = np.array([X[rot == k].mean(axis=0) if np.any(rot == k) else C[k] for k in range(3)])  # atualização

inercia = ((X - C[rot]) ** 2).sum()
sk = KMeans(3, init="random", n_init=1, random_state=0).fit(X)
print("Inércia (NumPy)       :", round(inercia, 1))
print("Inércia (scikit-learn):", round(sk.inertia_, 1))
```
@@NOTE Os valores ficam iguais ou muito próximos. Se forem diferentes, a causa é a inicialização (mínimo local). Rode com outra semente e veja.
@@EX 2 | Escolhendo k com inércia e silhueta | básico
Gere 500 pontos com 5 grupos (`make_blobs`, `random_state=3`, `cluster_std=0.9`). Para k de 2 a 9, calcule a inércia e a silhueta. Monte um `DataFrame` e indique o k de maior silhueta.
@@SOL
```python
import pandas as pd
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

X, _ = make_blobs(500, centers=5, cluster_std=0.9, random_state=3)
linhas = []
for k in range(2, 10):
    km = KMeans(k, n_init=10, random_state=0).fit(X)
    linhas.append({"k": k, "inercia": km.inertia_, "silhueta": silhouette_score(X, km.labels_)})
tab = pd.DataFrame(linhas)
print(tab.round(3).to_string(index=False))
print("k de maior silhueta:", int(tab.loc[tab.silhueta.idxmax(), "k"]))
```
@@NOTE A inércia cai sempre; a silhueta tem um máximo claro em k = 5 se os grupos estão bem separados. Se houver grupos sobrepostos, os dois critérios podem discordar.
@@EX 3 | Aleatória ou k-means++? | intermediário
Compare as inicializações `"random"` e `"k-means++"` rodando `KMeans` com `n_init=1` em 100 sementes diferentes sobre dados com 8 grupos (`make_blobs(1000, centers=8, random_state=1)`). Para cada método, calcule a média e o desvio padrão da inércia e a proporção de execuções que atingiram a melhor inércia observada (com tolerância de 1%).
@@SOL
```python
import numpy as np
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans

X, _ = make_blobs(1000, centers=8, random_state=1)
res = {}
for init in ["random", "k-means++"]:
    res[init] = np.array([KMeans(8, init=init, n_init=1, random_state=s).fit(X).inertia_ for s in range(100)])
melhor = min(r.min() for r in res.values())
for init, r in res.items():
    print(f"{init:10s} média = {r.mean():8.1f}  desvio = {r.std():7.1f}  acertou o melhor = {(r <= melhor * 1.01).mean():.0%}")
```
@@NOTE O k-means++ costuma ter média menor, menos variação e mais execuções boas, como previsto por Arthur e Vassilvitskii (2007).
@@EX 4 | Mini-Batch K-means em dados grandes | intermediário
Gere 200 mil pontos (`make_blobs`, 6 grupos, 10 atributos). Compare `KMeans` e `MiniBatchKMeans` em **tempo** (use `time.perf_counter`) e **inércia**. Calcule a razão entre as inércias.
@@SOL
```python
import time
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans, MiniBatchKMeans

X, _ = make_blobs(200_000, centers=6, n_features=10, random_state=0)
for nome, modelo in [("KMeans", KMeans(6, n_init=3, random_state=0)),
                     ("MiniBatchKMeans", MiniBatchKMeans(6, batch_size=2048, n_init=3, random_state=0))]:
    t0 = time.perf_counter(); modelo.fit(X); dt = time.perf_counter() - t0
    print(f"{nome:16s} tempo = {dt:5.2f} s   inércia = {modelo.inertia_:,.0f}")
```
@@NOTE O Mini-Batch costuma ser bem mais rápido e ter inércia apenas ligeiramente maior. Os tempos exatos dependem do seu computador.
@@EX 5 | Quantização de cores de uma foto | avançado
Carregue uma imagem de exemplo com `load_sample_images`. Transforme os pixels em pontos RGB e use K-means com 8, 16 e 32 cores (ajuste o modelo em uma **amostra de 10 mil pixels**, depois aplique a todos). Para cada k, calcule o erro quadrático médio da imagem reconstruída e a razão de compressão aproximada (24 bits por pixel antes; log2(k) bits por pixel depois, ignorando a paleta).
@@SOL
```python
import numpy as np
from sklearn.datasets import load_sample_images
from sklearn.cluster import KMeans

img = load_sample_images().images[0] / 255.0          # (altura, largura, 3)
h, w, _ = img.shape
px = img.reshape(-1, 3)
rng = np.random.default_rng(0)
amostra = px[rng.choice(len(px), 10_000, replace=False)]

for k in [8, 16, 32]:
    km = KMeans(k, n_init=3, random_state=0).fit(amostra)
    q = km.cluster_centers_[km.predict(px)].reshape(h, w, 3)
    mse = np.mean((img - q) ** 2)
    print(f"k = {k:2d}  MSE = {mse:.5f}  compressão ≈ {24 / np.log2(k):.1f}x")
```
@@NOTE Mais cores significam menor erro e menos compressão. A amostragem de pixels torna o ajuste rápido sem perda visível.
@@PROJ Segmentação RFM de uma loja | Cap03
**Contexto.** Uma loja virtual (fictícia) quer criar campanhas diferentes para tipos diferentes de clientes. Você receberá o histórico de compras e deverá produzir uma **segmentação RFM** (recência, frequência, valor) com K-means e **propor ações de marketing**.

**Dados.** Gere o histórico com a função abaixo.

```python
import numpy as np
import pandas as pd

def gerar_compras(seed=0):
    rng = np.random.default_rng(seed)
    perfis = [("fiel", 120, 22, 90.0), ("ocasional", 260, 5, 70.0), ("inativo", 150, 1.5, 55.0), ("vip", 60, 40, 220.0)]
    linhas, cid = [], 0
    for nome, n, freq, ticket in perfis:
        for _ in range(n):
            cid += 1
            k = max(1, rng.poisson(freq))
            dias = np.sort(rng.integers(0, 365 if nome != "inativo" else 150, k))
            for d in dias:
                linhas.append((cid, int(d), float(rng.gamma(4, ticket / 4)), nome))
    return pd.DataFrame(linhas, columns=["cliente", "dia", "valor", "perfil_oculto"])
```
O campo `dia` indica o dia da compra (0 a 364; hoje é o dia 365). `perfil_oculto` só deve ser usado no final.

**Tarefas.**
1. Calcule, por cliente, a **recência** (dias desde a última compra), a **frequência** (nº de compras) e o **valor** (soma gasta).
2. Aplique `log1p` em frequência e valor (distribuições assimétricas) e padronize.
3. Escolha k entre 2 e 8 usando cotovelo e silhueta.
4. Treine o K-means final, calcule o **perfil médio** de cada segmento (em unidades originais) e dê um **nome** a cada um.
5. Verifique a **estabilidade**: repita a segmentação em 20 reamostragens (80% dos clientes) e calcule o ARI médio entre as soluções.
6. Proponha uma **ação de marketing** para cada segmento.
7. Só no final, compare com `perfil_oculto` (ARI).

**Entregáveis.** Script comentado, tabela de perfis, gráfico do cotovelo/silhueta e texto com ações propostas.
@@SOL
```python
import numpy as np
import pandas as pd
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score

def gerar_compras(seed=0):
    rng = np.random.default_rng(seed)
    perfis = [("fiel", 120, 22, 90.0), ("ocasional", 260, 5, 70.0), ("inativo", 150, 1.5, 55.0), ("vip", 60, 40, 220.0)]
    linhas, cid = [], 0
    for nome, n, freq, ticket in perfis:
        for _ in range(n):
            cid += 1
            k = max(1, rng.poisson(freq))
            dias = np.sort(rng.integers(0, 365 if nome != "inativo" else 150, k))
            for d in dias:
                linhas.append((cid, int(d), float(rng.gamma(4, ticket / 4)), nome))
    return pd.DataFrame(linhas, columns=["cliente", "dia", "valor", "perfil_oculto"])

compras = gerar_compras()
rfm = compras.groupby("cliente").agg(recencia=("dia", lambda d: 365 - d.max()),
                                     frequencia=("dia", "size"), valor=("valor", "sum"),
                                     perfil=("perfil_oculto", "first"))
print("Clientes:", len(rfm))

Xr = rfm[["recencia", "frequencia", "valor"]].copy()
Xr[["frequencia", "valor"]] = np.log1p(Xr[["frequencia", "valor"]])
Xp = StandardScaler().fit_transform(Xr)

for k in range(2, 9):
    km = KMeans(k, n_init=10, random_state=0).fit(Xp)
    print(f"k={k}  inércia={km.inertia_:7.1f}  silhueta={silhouette_score(Xp, km.labels_):.3f}")

K = 4
km = KMeans(K, n_init=10, random_state=0).fit(Xp)
rfm["segmento"] = km.labels_
print(rfm.groupby("segmento")[["recencia", "frequencia", "valor"]].mean().round(1).assign(n=rfm.segmento.value_counts().sort_index()))

rng = np.random.default_rng(1)
aris = []
for _ in range(20):
    i1 = rng.choice(len(Xp), int(0.8 * len(Xp)), replace=False)
    i2 = rng.choice(len(Xp), int(0.8 * len(Xp)), replace=False)
    m1 = KMeans(K, n_init=5, random_state=0).fit(Xp[i1]); m2 = KMeans(K, n_init=5, random_state=1).fit(Xp[i2])
    aris.append(adjusted_rand_score(m1.predict(Xp), m2.predict(Xp)))
print("Estabilidade (ARI médio):", round(float(np.mean(aris)), 3))
print("ARI contra o perfil oculto:", round(adjusted_rand_score(rfm.perfil, rfm.segmento), 3))
print(pd.crosstab(rfm.segmento, rfm.perfil))
```
@@RUBRICA
- RFM calculado corretamente (recência = hoje − último dia).
- Transformação logarítmica e padronização justificadas.
- k escolhido com mais de um critério e discutido.
- Segmentos nomeados a partir do perfil médio em unidades originais.
- Estabilidade avaliada com reamostragens.
- Cada segmento recebe uma ação coerente (por exemplo: fidelidade para VIPs, cupom de reativação para inativos).
@@NOTE Repare que a silhueta é ligeiramente maior para k = 3 (cerca de 0,60) do que para k = 4 (cerca de 0,59). Com k = 4, porém, o grupo dos clientes VIP se separa dos fiéis, o que tem grande valor de negócio. A escolha de k combina critérios numéricos e utilidade. Com k = 4, a estabilidade é alta (ARI médio de cerca de 0,95) e o ARI contra os perfis ocultos fica em torno de 0,82: os "ocasionais" e "inativos" se misturam em parte (33 ocasionais caem no grupo dos inativos). Discuta isso no relatório.
